# Основы Linux и запуск системы

## Процесс загрузки Linux

Загрузка Linux - последовательность действий от включения компьютера до готовой системы. Упрощённо процесс выглядит так:

1. Включение компьютера.
2. BIOS / UEFI.
3. загрузчик (обычно GRUB).
4. ядро Linux.
5. initramfs.
6. init / systemd.
7. запуск служб.
8. терминал или графический интерфейс.

### BIOS / UEFI

При включении компьютера BIOS или UEFI:

- инициализирует оборудование.
- проверяет оперативную память и основные устройства.
- определяет, откуда загружать операционную систему.
- передаёт управление загрузчику.

В старых системах используется схема BIOS + MBR, в современных - UEFI с EFI-разделом.

### Загрузчик

**Загрузчик (Bootloader)** находит и запускает операционную систему. В Linux чаще всего используется **GRUB**. Он:

- может показывать меню выбора ОС.
- загружает ядро Linux в оперативную память.
- загружает `initramfs`.
- передаёт управление ядру.

## Ядро при загрузке

После загрузки ядро:

- настраивает оперативную память.
- обнаруживает процессоры.
- инициализирует оборудование.
- загружает необходимые драйверы.
- получает доступ к корневой файловой системе.
- запускает первый пользовательский процесс.

## initramfs

**initramfs** - временная файловая система, загружаемая в оперативную память на раннем этапе запуска. Она содержит минимальный набор программ и драйверов, необходимых для:

- обнаружения устройств.
- загрузки необходимых драйверов.
- поиска корневой файловой системы.
- её проверки и монтирования.

После подключения настоящей корневой файловой системы работа передаётся системе инициализации.

## init и systemd

После подготовки системы ядро запускает `/sbin/init`. Это первый пользовательский процесс, от которого запускается большинство остальных процессов системы. В современных дистрибутивах эту роль обычно выполняет `systemd`. systemd отвечает за:

- запуск системы.
- запуск и остановку служб.
- управление зависимостями между службами.
- завершение работы и перезагрузку системы.

Для управления службами используется `systemctl`. Примеры использования:

Запустить службу:

```bash
sudo systemctl start service
```

Остановить:

```bash
sudo systemctl stop service
```

Перезапустить:

```bash
sudo systemctl restart service
```

Включить автоматический запуск при загрузке:

```bash
sudo systemctl enable service
```

Отключить:

```bash
sudo systemctl disable service
```

## Вход в систему

После загрузки пользователь может получить:

- графический экран входа.
- текстовый терминал.

После ввода имени пользователя и пароля запускается командная оболочка. Часто используется `Bash`. Она принимает команды пользователя и передаёт их системе для выполнения.

# Файловая система Linux

**Файловая система** определяет способ хранения и организации файлов на носителе. Linux поддерживает множество файловых систем, например:

- `ext4`.
- `XFS`.
- `Btrfs`.
- `NTFS`.
- `exFAT`.

## Раздел и файловая система

Важно различать:

**Раздел (partition)** - логически выделенная часть диска.

**Файловая система (filesystem)** - способ организации и хранения файлов внутри раздела.

## Монтирование

В Linux нет букв дисков вроде `C: D: E:`. Вместо этого все файловые системы подключаются к единому дереву каталогов. Главная точка этого дерева `/`. Подключение файловой системы к определённому каталогу называется **монтированием (mounting)**, а каталог - **точкой монтирования (mount point)**. Например, USB-накопитель может быть доступен через:

```text
/run/media/user/USB
```

## Иерархия файловой системы

Linux использует стандарт **FHS (Filesystem Hierarchy Standard)**, который определяет общую структуру каталогов. Все пути начинаются от:

```text
/
```

Linux использует `/` в путях:

```text
/home/user/file.txt
```

в отличие от Windows:

```text
C:\Users\User\file.txt
```

Linux также чувствителен к регистру:

```text
/boot
/Boot
/BOOT
```

Это три разных имени.

# Выбор дистрибутива

При выборе Linux-дистрибутива учитывают:

- назначение системы: сервер, ПК или встроенное устройство.
- необходимое программное обеспечение.
- аппаратную платформу.
- объём диска.
- частоту обновлений.
- срок поддержки.
- необходимость стабильности.
- необходимость новейших версий программ.

Например, **LTS**-выпуски ориентированы на длительную поддержку и стабильность.

# Установка Linux

Перед установкой нужно определить:

- разделы диска.
- необходимое программное обеспечение.
- пользователей.
- способ установки.
- нужно ли сохранять существующую ОС.

Во время установки обычно создаётся обычный пользователь и настраиваются права администратора. В некоторых дистрибутивах, например Ubuntu, административные действия выполняются через `sudo`.

## Способы установки

Linux можно установить:

1. как единственную ОС.
2. рядом с другой ОС - Dual Boot.
3. в виртуальной машине.
4. запустить с Live USB без установки на диск.

При изменении разделов диска необходимо быть осторожным, поскольку неправильная настройка может привести к удалению существующих данных.

# Что важно запомнить

1. Загрузка Linux проходит через BIOS/UEFI -> загрузчик -> ядро -> initramfs -> systemd.
2. GRUB - распространённый загрузчик Linux.
3. `initramfs` помогает ядру получить доступ к основной файловой системе.
4. `systemd` управляет запуском системы и службами.
5. `systemctl` используется для управления службами.
6. Раздел диска и файловая система - разные понятия.
7. Корень всей файловой системы Linux - `/`.
8. В Linux нет букв дисков - файловые системы монтируются в каталоги.
9. Пути Linux чувствительны к регистру.
10. При выборе дистрибутива важны назначение, стабильность, поддержка и необходимое ПО.
