# Операции с файлами

## Файловые системы

## Принцип «всё является файлом»

В Linux часто используется принцип:

```text
Everything is a file
```

Многие объекты системы представлены как файлы или файлоподобные объекты. Это относится не только к обычным документам, но также к:

- устройствам.
- дискам.
- принтерам.
- некоторым данным ядра.
- другим системным объектам.

Благодаря этому с разными объектами можно работать через схожие операции чтения и записи.

## Дерево файловой системы

Файловая система Linux имеет иерархическую структуру. Всё начинается с корневого каталога:

```text
/
```

Например:

```text
/usr/bin/program
```

Где:

```text
/       -> корень
/usr    -> каталог
/bin    -> подкаталог
program -> файл
```

Важно:

```text
/      -> корневой каталог файловой системы
/root  -> домашний каталог пользователя root
```

Это разные понятия.

## Типы файловых систем

Linux поддерживает множество файловых систем. Распространённые из них:

```text
ext4
XFS
Btrfs
```

Также поддерживаются файловые системы других ОС:

```text
NTFS
VFAT
HFS+
```

Журналируемые файловые системы, например `ext4`, `XFS` и `Btrfs`, предназначены для надёжной работы и помогают снизить вероятность повреждения файловой системы после сбоев.

## Разделы диска

**Раздел (partition)** - логически выделенная часть диска. Разные данные можно размещать на отдельных разделах. Например:

```text
/      -> системные файлы
/home  -> данные пользователей
```

Разделение позволяет изолировать разные части системы друг от друга.

## Монтирование

Перед использованием файловую систему необходимо подключить к общему дереву каталогов Linux. Этот процесс называется:

```text
mounting
```

Каталог, куда подключается файловая система, называется:

```text
mount point
```

Например:

```bash
sudo mount /dev/sda5 /home
```

означает:

```text
/dev/sda5 -> файловая система/раздел
/home     -> точка монтирования
```

Посмотреть все смонтированные файловые системы:

```bash
mount
```

## Демонтирование

Для отключения файловой системы используется:

```bash
sudo umount /home
```

Важно: команда называется именно:

```text
umount
```

а не `unmount`.

## /etc/fstab

Файл `/etc/fstab` содержит конфигурацию файловых систем, которые должны автоматически монтироваться системой. Например, его используют, чтобы подключать диск автоматически при загрузке Linux.

## df

Посмотреть использование дискового пространства:

```bash
df -Th
```

Команда показывает:

- файловые системы.
- их тип.
- общий объём.
- использованное место.
- свободное место.
- точку монтирования.

## Сетевые файловые системы

## NFS

**NFS (Network File System)** позволяет предоставлять каталоги одной Linux-машины другим компьютерам через сеть. Например, домашние каталоги пользователей могут храниться на сервере, чтобы пользователь видел одинаковые файлы при входе с разных компьютеров.

## NFS-сервер

Для NFS используется системная служба. Пример запуска:

```bash
sudo systemctl start nfs
```

В некоторых дистрибутивах служба может называться:

```text
nfs-server
```

Каталоги, предоставляемые через NFS, указываются в:

```text
/etc/exports
```

После изменения конфигурации можно применить её:

```bash
exportfs -av
```

Включить автоматический запуск NFS:

```bash
sudo systemctl enable nfs
```

## NFS-клиент

Удалённую файловую систему можно подключить командой:

```bash
sudo mount server:/projects /mnt/nfs/projects
```

Чтобы подключение выполнялось автоматически после перезагрузки, его добавляют в:

```text
/etc/fstab
```

## Основные каталоги Linux

### /home

Домашние каталоги обычных пользователей:

```text
/home/user
```

Здесь обычно хранятся:

- личные файлы.
- пользовательские настройки.
- конфигурационные файлы пользователя.

### /root

Домашний каталог суперпользователя:

```text
/root
```

Не путать с:

```text
/
```

### /bin

Основные команды системы. Например:

```text
cat
cp
ls
mv
ps
rm
```

### /sbin

Основные программы системного администрирования. Например:

```text
fsck
ip
```

В современных системах `/bin` и `/sbin` могут фактически быть связаны с соответствующими каталогами внутри `/usr`.

### /proc

`/proc` - виртуальная псевдофайловая система. Она существует в памяти и предоставляет информацию о работающей системе и ядре. Примеры:

```text
/proc/cpuinfo
/proc/meminfo
/proc/mounts
/proc/partitions
```

Также для каждого процесса существует каталог:

```text
/proc/<PID>
```

Например:

```text
/proc/1234
```

содержит информацию о процессе с PID `1234`.

### /dev

Содержит файловые представления устройств. Например:

```text
/dev/sda1
/dev/random
```

Записи в `/dev` создаются и управляются системой `udev`.

### /var

Содержит данные, которые изменяются во время работы системы. Основные подкаталоги:

```text
/var/log   -> системные журналы
/var/lib   -> данные приложений и пакетов
/var/spool -> очереди
/var/tmp   -> временные файлы
```

### /etc

Содержит системные конфигурационные файлы. Примеры:

```text
/etc/fstab
/etc/passwd
/etc/shadow
/etc/group
/etc/resolv.conf
```

Обычно изменять файлы в `/etc` может только администратор.

### /boot

Содержит файлы, необходимые для загрузки Linux. Среди них:

```text
vmlinuz
initramfs
config
System.map
```

Также здесь находятся файлы загрузчика GRUB.

### /lib и /lib64

Содержат системные библиотеки, необходимые программам. Также здесь находятся модули ядра:

```text
/lib/modules/<kernel-version>
```

### /media, /run и /mnt

Используются для монтирования файловых систем.

```text
/run/media/... -> автоматическое подключение съёмных устройств
/mnt           -> временное ручное монтирование
```

## Другие каталоги

```text
/opt -> дополнительное программное обеспечение
/sys -> информация о системе и оборудовании
/srv -> данные системных сервисов
/tmp -> временные файлы
/usr -> программы, библиотеки и системные данные
```

## Каталог /usr

Основные подкаталоги:

```text
/usr/bin     -> большинство пользовательских команд
/usr/sbin    -> системные программы
/usr/lib     -> библиотеки
/usr/share   -> общие данные программ
/usr/src     -> исходный код
/usr/local   -> программы и данные локальной системы
```

## Сравнение файлов

### diff

`diff` сравнивает текстовые файлы.

```bash
diff file1 file2
```

Полезные параметры:

```text
-c -> показать контекст вокруг различий
-r -> рекурсивно сравнить каталоги
-i -> игнорировать регистр
-w -> игнорировать различия в пробелах
-q -> только сообщить, отличаются ли файлы
```

Для сравнения бинарных файлов можно использовать:

```text
cmp
```

### diff3

Позволяет сравнить три версии файла:

```bash
diff3 MY-FILE COMMON-FILE YOUR-FILE
```

Полезно, когда два человека изменили один исходный файл независимо друг от друга.

## Patch

**Patch** - файл, содержащий различия между версиями файлов. Создать patch:

```bash
diff -Nur original new > patchfile
```

Применить:

```bash
patch -p1 < patchfile
```

Патч удобнее передавать, чем целый большой файл, если изменена только небольшая его часть.

## Определение типа файла

В Linux расширение файла не обязательно определяет его реальный тип. Например:

```text
file.txt
```

не обязан быть текстовым файлом. Для определения типа используется:

```bash
file filename
```

Команда анализирует содержимое файла и определяет, является ли он:

- текстом.
- исполняемым файлом.
- библиотекой.
- скриптом.
- архивом.
- другим типом объекта.

## Резервное копирование

### cp

Обычное копирование:

```bash
cp source destination
```

Подходит для простого локального копирования.

### rsync

`rsync` используется для синхронизации файлов и каталогов. Основное преимущество:

```text
копируются только необходимые изменения
```

Поэтому повторная синхронизация обычно выполняется намного быстрее. Пример:

```bash
rsync -r project-X archive-machine:archives/project-X
```

`rsync` может работать как:

```text
локальная машина -> локальная машина
локальная машина -> удалённая машина
удалённая машина -> локальная машина
```

Перед потенциально опасной синхронизацией полезно сначала проверить результат в тестовом режиме:

```bash
rsync --dry-run ...
```

Нужно внимательно проверять source и destination, поскольку неправильная команда может привести к нежелательным изменениям данных.

## Сжатие файлов

Основные инструменты:

```text
gzip
bzip2
xz
zip
```

В общем виде:

```text
gzip  -> быстрое и распространённое сжатие
bzip2 -> более сильное, но более медленное сжатие
xz    -> высокая степень сжатия, но медленнее
zip   -> распространённый формат для совместимости с другими ОС
```

### gzip

Сжать файл:

```bash
gzip file
```

Получится:

```text
file.gz
```

Распаковать:

```bash
gunzip file.gz
```

или:

```bash
gzip -d file.gz
```

### bzip2

Сжать:

```bash
bzip2 file
```

Получится:

```text
file.bz2
```

Распаковать:

```bash
bunzip2 file.bz2
```

### xz

Сжать:

```bash
xz file
```

Получится:

```text
file.xz
```

Распаковать:

```bash
xz -d file.xz
```

## Архивирование с tar

`tar` объединяет несколько файлов и каталогов в один архив. Такой архив часто называют:

```text
tarball
```

Создать обычный tar-архив:

```bash
tar cvf archive.tar directory
```

Распаковать:

```bash
tar xvf archive.tar
```

### tar + gzip

Создать:

```bash
tar zcvf archive.tar.gz directory
```

Распаковать:

```bash
tar xvf archive.tar.gz
```

### tar + bzip2

```bash
tar jcvf archive.tar.bz2 directory
```

### tar + xz

```bash
tar Jcvf archive.tar.xz directory
```

Упрощённо:

```text
tar -> объединяет файлы в архив
gzip / bzip2 / xz -> сжимают данные
```

## dd

`dd` используется для низкоуровневого копирования данных и может создавать точные копии дисков или разделов. Например:

```bash
dd if=/dev/sda of=sda.mbr bs=512 count=1
```

Здесь:

```text
if -> input file
of -> output file
bs -> размер блока
count -> количество блоков
```

`dd` - потенциально очень опасная команда. Например:

```bash
dd if=/dev/sda of=/dev/sdb
```

Полностью перезапишет содержимое `/dev/sdb`. Перед выполнением `dd` необходимо особенно внимательно проверять `if` и `of`.

## Что важно запомнить

1. Файловая система Linux представляет собой дерево с корнем `/`.
2. `/` и `/root` - разные вещи.
3. Файловые системы подключаются к дереву через точки монтирования.
4. `mount` подключает файловую систему, `umount` отключает её.
5. `/etc/fstab` используется для автоматического монтирования.
6. `df -Th` показывает использование файловых систем.
7. NFS позволяет предоставлять файлы другим системам через сеть.
8. `/home` содержит домашние каталоги пользователей.
9. `/etc` содержит системную конфигурацию.
10. `/var` содержит изменяемые данные, в том числе логи.
11. `/boot` содержит файлы, необходимые для загрузки.
12. `/proc` - виртуальная файловая система с информацией о ядре и процессах.
13. `/dev` содержит представления устройств.
14. `diff` сравнивает файлы, а `patch` применяет набор изменений.
15. Расширение файла в Linux не обязательно определяет его тип.
16. `file` помогает определить настоящий тип файла.
17. `rsync` удобен для резервного копирования и синхронизации.
18. `tar` создаёт архив, а `gzip`, `bzip2` и `xz` используются для сжатия.
19. `dd` работает с данными на низком уровне и требует особой осторожности.
