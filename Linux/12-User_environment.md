# Среда пользователя

## Пользователи Linux

Linux - многопользовательская система: одновременно с системой могут работать несколько пользователей.

### whoami

Показывает текущего пользователя:

```bash
whoami
```

### who

Показывает пользователей, которые сейчас вошли в систему:

```bash
who
```

Более подробная информация:

```bash
who -a
```

## Файлы запуска Bash

При запуске оболочки Bash используются специальные конфигурационные файлы. Они позволяют настраивать:

- командную строку.
- псевдонимы.
- редактор по умолчанию.
- переменные окружения.
- пути поиска программ.

## Глобальные настройки

Настройки для всех пользователей находятся в:

```text
/etc/profile
```

## Пользовательские настройки

При входе в систему Bash ищет файлы в следующем порядке:

```text
~/.bash_profile
~/.bash_login
~/.profile
```

Используется первый найденный файл. При открытии нового терминала обычно используется:

```text
~/.bashrc
```

Поэтому именно `~/.bashrc` чаще всего изменяют для настройки своей командной оболочки. После изменения `.bashrc` настройки можно применить без перезапуска терминала:

```bash
source ~/.bashrc
```

или:

```bash
. ~/.bashrc
```

## Псевдонимы - alias

**Alias** позволяет создать сокращение для команды или изменить её обычное поведение. Постоянные пользовательские псевдонимы обычно добавляют в:

```text
~/.bashrc
```

Посмотреть существующие псевдонимы:

```bash
alias
```

Удалить псевдоним:

```bash
unalias
```

При создании alias вокруг знака `=` не должно быть пробелов. Если команда содержит пробелы, её заключают в кавычки.

## Пользователи и группы

Каждый пользователь Linux имеет уникальный:

```text
UID - User ID
```

Обычные пользователи обычно имеют UID начиная примерно с:

```text
1000
```

Пользователи объединяются в группы. Каждая группа имеет:

```text
GID - Group ID
```

Группы позволяют назначать одинаковые права сразу нескольким пользователям. Информация о пользователях и группах связана с файлами:

```text
/etc/passwd
/etc/group
```

Каждый пользователь имеет основную группу и может одновременно входить в дополнительные группы.

## Управление пользователями

Создать пользователя:

```bash
sudo useradd username
```

При создании обычно формируется домашний каталог:

```text
/home/username
```

и добавляется запись в:

```text
/etc/passwd
```

Удалить пользователя:

```bash
sudo userdel username
```

При этом домашний каталог пользователя автоматически не удаляется. Удалить пользователя вместе с домашним каталогом:

```bash
sudo userdel -r username
```

## id

Показать UID, GID и группы текущего пользователя:

```bash
id
```

Для другого пользователя:

```bash
id username
```

## Управление группами

Создать группу:

```bash
sudo groupadd groupname
```

Удалить:

```bash
sudo groupdel groupname
```

Посмотреть группы пользователя:

```bash
groups username
```

Добавить пользователя в дополнительную группу:

```bash
sudo usermod -a -G groupname username
```

Важно использовать:

```text
-a
```

при добавлении пользователя в группу, чтобы не удалить его существующее членство в других группах.

## root, su и sudo

### root

`root` - суперпользователь Linux с практически полным доступом к системе. Постоянно работать под `root` не рекомендуется, поскольку ошибка может затронуть всю систему.

### su

`su` запускает оболочку от имени другого пользователя. Чаще всего используется для перехода к `root`.

```bash
su
```

После этого требуется пароль пользователя, на которого выполняется переключение.

### sudo

`sudo` позволяет выполнить отдельную команду с повышенными привилегиями:

```bash
sudo command
```

После выполнения команды пользователь продолжает работать с обычными правами. Поэтому обычно:

```text
sudo -> предпочтительнее для отдельных административных действий
su   -> переключает на другого пользователя на более длительное время
```

Конфигурация `sudo` хранится в:

```text
/etc/sudoers
/etc/sudoers.d/
```

## Переменные окружения

**Environment variables** - переменные, содержащие информацию, которую используют Shell и другие программы. Посмотреть переменные можно командами:

```bash
set
env
export
```

Посмотреть конкретную переменную:

```bash
echo $VARIABLE
```

Например:

```bash
echo $SHELL
```

## Создание переменной

```bash
VARIABLE=value
```

Чтобы переменная была доступна дочерним процессам:

```bash
export VARIABLE=value
```

Чтобы сохранить её постоянно, запись можно добавить в:

```text
~/.bashrc
```

а затем выполнить:

```bash
source ~/.bashrc
```

## HOME

Переменная:

```text
HOME
```

содержит путь к домашнему каталогу пользователя. Посмотреть:

```bash
echo $HOME
```

Например:

```text
/home/user
```

Команды:

```bash
cd
```

```bash
cd $HOME
```

```bash
cd ~
```

ведут в домашний каталог пользователя.

## PATH

`PATH` - список каталогов, в которых Shell ищет программы после ввода команды. Посмотреть:

```bash
echo $PATH
```

Каталоги разделяются:

```text
:
```

Например:

```text
/usr/local/bin:/usr/bin:/bin
```

Добавить собственный каталог:

```bash
export PATH=$HOME/bin:$PATH
```

После этого Shell также будет искать программы в:

```text
$HOME/bin
```

## SHELL

Переменная:

```text
SHELL
```

показывает оболочку пользователя по умолчанию.

```bash
echo $SHELL
```

Например:

```text
/bin/bash
```

## PS1

`PS1` определяет внешний вид приглашения командной строки. Некоторые обозначения:

```text
\u -> имя пользователя
\h -> имя компьютера
\w -> текущий каталог
\! -> номер команды в истории
\d -> дата
```

Например:

```text
user@computer:~$
```

может содержать имя пользователя, hostname и текущий каталог.

## История команд

Bash сохраняет ранее выполненные команды. Посмотреть историю:

```bash
history
```

История сохраняется в:

```text
~/.bash_history
```

## Повторное использование команд

Стрелки:

```text
↑ / ↓
```

перемещаются по истории команд. Выполнить предыдущую команду:

```bash
!!
```

Найти старую команду:

```text
Ctrl + R
```

После `Ctrl+R` можно начать вводить часть команды, и Bash будет искать совпадение в истории.

## Дополнительный синтаксис истории

```text
!n       -> выполнить команду №n
!string  -> последняя команда, начинающаяся с string
!$       -> последний аргумент предыдущей команды
```

## Полезные горячие клавиши Bash

```text
Ctrl + L -> очистить экран
Ctrl + D -> выйти из текущей оболочки
Ctrl + C -> завершить текущий процесс
Ctrl + Z -> приостановить текущий процесс
Ctrl + A -> начало строки
Ctrl + E -> конец строки
Ctrl + W -> удалить слово перед курсором
Ctrl + U -> удалить текст от курсора до начала строки
Tab      -> автодополнение
```

Особенно полезно:

```text
Tab
```

Bash может автоматически дополнять:

- команды.
- имена файлов.
- каталоги.

## Права доступа к файлам

Каждый файл Linux имеет:

```text
владельца
группу
права доступа
```

Основные команды:

```text
chmod -> изменить права
chown -> изменить владельца
chgrp -> изменить группу
```

## Типы прав

Существует три основных разрешения:

```text
r → read    -> чтение
w → write   -> запись
x → execute -> выполнение
```

Они задаются отдельно для:

```text
u -> user  -> владелец
g -> group -> группа
o -> other -> остальные
```

Например:

```text
rwxr-xr--
```

можно разделить как:

```text
rwx | r-x | r--
 u  |  g  |  o
```

То есть:

```text
владелец -> чтение + запись + выполнение
группа   -> чтение + выполнение
остальные -> только чтение
```

## chmod

`chmod` изменяет права доступа. Символьный вариант:

```bash
chmod uo+x,g-w somefile
```

Здесь:

```text
u -> user
g -> group
o -> others

+ -> добавить право
- -> удалить право
```

## Числовые права chmod

Каждому разрешению соответствует число:

```text
r = 4
w = 2
x = 1
```

Значения складываются.

```text
7 = 4 + 2 + 1 = rwx
6 = 4 + 2     = rw-
5 = 4 + 1     = r-x
4 = 4         = r--
```

Команда состоит из трёх цифр:

```text
owner | group | others
```

Например:

```bash
chmod 755 file
```

означает:

```text
7 -> rwx -> владелец
5 -> r-x -> группа
5 -> r-x -> остальные
```

Итог:

```text
rwxr-xr-x
```

Ещё один распространённый пример:

```text
644
```

означает:

```text
rw-r--r--
```

## chown и chgrp

Изменить владельца файла:

```bash
chown owner filename
```

Изменить группу:

```bash
chgrp group filename
```

Для изменения владельца обычно необходимы административные права.

9. `~/.bashrc` - основной пользовательский файл настройки Bash для новых оболочек.
10. Переменные окружения можно посмотреть через `env`, `set` или `export`.
11. `HOME` содержит домашний каталог пользователя.
12. `PATH` определяет, где Shell ищет выполняемые программы.
13. `SHELL` указывает оболочку пользователя по умолчанию.
14. `history` показывает ранее выполненные команды.
15. `Ctrl+R` позволяет искать по истории.
16. `Tab` выполняет автодополнение.
17. Файл имеет владельца, группу и права доступа.
18. `r = 4`, `w = 2`, `x = 1`.
19. `chmod 755` соответствует `rwxr-xr-x`.
20. `chmod` меняет права, `chown` - владельца, `chgrp` - группу.
