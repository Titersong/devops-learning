# The Linux Foundation и семейства дистрибутивов Linux

## The Linux Foundation

**The Linux Foundation** - организация, которая поддерживает Linux и множество других проектов с открытым исходным кодом. Она предоставляет разработчикам инфраструктуру, обучение и площадки для совместной работы над открытыми технологиями. Деятельность организации охватывает:

- Linux.
- облачные технологии.
- сети.
- контейнеры.
- безопасность.
- встроенные системы и IoT.
- другие проекты с открытым исходным кодом.

## Обучение Linux

The Linux Foundation проводит обучение по системному администрированию, DevOps, облачным технологиям, сетям, разработке ядра Linux и другим направлениям. Большая часть обучения ориентирована на практические задания и развитие навыков, которые можно применять в реальной работе.

## Дистрибутив Linux

**Дистрибутив** - готовая операционная система на основе Linux, включающая ядро, системные программы, пакетный менеджер и другие компоненты. В курсе рассматриваются три основные семьи дистрибутивов:

```text
Red Hat
SUSE
Debian
```

Для практики достаточно установить хотя бы один дистрибутив Linux.

## Семейство Red Hat

К семейству Red Hat относятся:

- Red Hat Enterprise Linux.
- CentOS Stream.
- Fedora.
- Oracle Linux.

**Fedora** используется как площадка для внедрения и проверки новых технологий, которые позднее могут появиться в RHEL. Для управления программами применяются пакеты формата RPM и менеджеры пакетов `dnf` или `yum`.

## Семейство SUSE

Основные представители:

- SUSE Linux Enterprise Server.
- openSUSE.

Для управления пакетами используется ```zypper```. Для настройки и администрирования системы также применяется инструмент **YaST**.

## Семейство Debian

К семейству Debian относятся:

- Debian.
- Ubuntu.
- Linux Mint.

Debian ориентирован на стабильность и располагает большим хранилищем программного обеспечения. Ubuntu основана на Debian и стремится сочетать стабильность с простотой использования. В курсе в качестве основного представителя этого семейства используется Ubuntu LTS. Для управления пакетами применяются `APT` и `DPKG`:

```bash
apt
apt-get
apt-cache
```

## Различия между дистрибутивами

Основные принципы Linux почти одинаковы во всех современных дистрибутивах. Различия обычно связаны с:

- пакетными менеджерами.
- версиями программ.
- расположением некоторых файлов.
- системными инструментами.
- внешним видом рабочего окружения.

После понимания этих различий переходить между дистрибутивами становится проще. В курсе для графического интерфейса используется рабочее окружение **GNOME**.

## Что важно запомнить

1. The Linux Foundation поддерживает Linux и другие проекты с открытым исходным кодом.
2. Дистрибутив - готовая система, созданная на основе Linux.
3. В курсе рассматриваются семьи Red Hat, SUSE и Debian.
4. Red Hat использует RPM и `dnf` или `yum`.
5. SUSE использует RPM, `zypper` и инструмент YaST.
6. Debian и Ubuntu используют DPKG и APT.
7. Ubuntu LTS является основным представителем семейства Debian в курсе.
8. Большинство базовых знаний Linux применимо к разным дистрибутивам.
