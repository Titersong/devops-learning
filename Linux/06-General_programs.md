# Общие программы Linux

## Интернет-программы

В Linux доступны разные программы для работы с интернетом:

- веббраузеры.
- почтовые клиенты.
- программы обмена сообщениями.
- мультимедийные сервисы.
- программы для конференций.
- инструменты передачи файлов.

## Веббраузеры

Linux поддерживает как графические, так и текстовые браузеры. Примеры графических:

```text
Firefox
Google Chrome
Chromium
Epiphany
Opera
```

Примеры текстовых:

```text
lynx
w3m
```

Текстовые браузеры позволяют открывать сайты прямо из терминала.

## Электронная почта

Linux поддерживает как графические, так и текстовые почтовые клиенты. Графические:

```text
Thunderbird
Evolution
Claws Mail
```

Текстовые:

```text
Mutt
mail
```

Также можно использовать обычные веб-сервисы через браузер. Для получения почты обычно применяются протоколы:

- IMAP.
- POP.

## Другие сетевые программы

### FileZilla

Графическая программа для передачи файлов. Поддерживает:

```text
FTP
SFTP
FTPS
```

### Pidgin

Клиент для различных систем обмена сообщениями.

### HexChat

Клиент для общения через IRC.

## Офисные программы

### LibreOffice

Большинство дистрибутивов Linux предлагают офисный пакет:

```text
LibreOffice
```

Основные компоненты:

- **Writer** - работа с текстовыми документами.
- **Calc** - электронные таблицы.
- **Impress** - презентации.
- **Draw** - графики и диаграммы.

LibreOffice также умеет работать с форматами Microsoft Office, хотя сложные документы иногда могут отображаться не полностью одинаково.

## Инструменты разработчика

Linux предоставляет большое количество инструментов для разработки программ.

### Текстовые редакторы

Например:

```text
vi
emacs
```

### Компиляторы

Например:

```text
gcc
clang
```

Также Linux поддерживает большое количество языков программирования, включая:

```text
Go
Rust
```

### Отладчики

Для поиска ошибок используются:

```text
gdb
Valgrind
```

### IDE

Также доступны полноценные среды разработки:

```text
Eclipse
Visual Studio Code
```

## Мультимедиа

### Аудио

Примеры программ:

- **Amarok** - аудиоплеер.
- **Audacity** - запись и редактирование аудио.
- **Rhythmbox** - музыка, интернет-радио и подкасты.

### Видео

Популярные видеоплееры:

```text
VLC
MPlayer
Xine
Totem
```

### Работа с видео

Примеры инструментов:

- **Blender** - 3D-графика, анимация и работа с видео.
- **Cinelerra** - работа с аудио и видео.
- **Cinepaint** - обработка изображений и кадров.
- **FFmpeg** - запись, конвертация и обработка аудио и видео.

Особенно полезный инструмент:

```text
FFmpeg
```

Он работает из командной строки и позволяет преобразовывать мультимедийные файлы между разными форматами.

## Графика

### GIMP

**GIMP** - графический редактор для создания и обработки изображений. Он поддерживает:

- слои.
- каналы.
- фильтры.
- плагины.
- разные форматы изображений.

По назначению его часто сравнивают с Adobe Photoshop.

## Другие графические программы

### Inkscape

Редактор графики, который часто сравнивают с Adobe Illustrator.

### eog

Простой просмотрщик изображений GNOME.

### ImageMagick / convert

Инструмент командной строки для обработки изображений. Позволяет:

- менять формат.
- изменять размер.
- применять различные преобразования.

### Scribus

Программа для вёрстки и подготовки документов к публикации.

## Что важно запомнить

1. Linux имеет как графические, так и терминальные приложения.
2. Доступны обычные браузеры вроде Firefox и Chrome, а также текстовые `lynx` и `w3m`.
3. Thunderbird, Evolution и Mutt используются для работы с электронной почтой.
4. LibreOffice - основной свободный офисный пакет.
5. Writer работает с текстом, Calc - с таблицами, Impress - с презентациями.
6. Linux предоставляет много встроенных инструментов для разработки.
7. `gcc` и `clang`  компиляторы.
8. `gdb` - отладчик.
9. VLC - популярный видеоплеер.
10. Audacity используется для работы со звуком.
11. FFmpeg - мощный инструмент для обработки мультимедиа из командной строки.
12. GIMP используется для растровой графики, а Inkscape - для графического редактирования.
