# Графический интерфейс Linux

## CLI и GUI

Linux предоставляет два основных способа взаимодействия:

- **CLI (Command Line Interface)** - работа через командную строку.
- **GUI (Graphical User Interface)** - графический интерфейс с окнами, меню и иконками.

GUI удобнее для обычных пользователей и операций. CLI эффективнее для повторяющихся задач и автоматизации.

## X Window и Wayland

**X Window (X)** - система, предоставляющая графические возможности приложениям Linux.

- **X Server** предоставляет графические службы приложениям.
- **Display Manager** отвечает за графический экран входа и запуск рабочего окружения.
- `startx` - позволяет запустить графический сеанс из текстовой консоли.

**Wayland** - более современная система отображения, постепенно заменяющая X.

## Display Manager

Display Manager:

- запускается во время загрузки.
- показывает экран входа.
- принимает имя пользователя и пароль.
- запускает выбранное рабочее окружение.

Популярные:

- `gdm` - стандартный для GNOME;
- `lightdm`;
- `kdm` - cтандартный для KDE;

## GNOME

**GNOME** - популярное графическое рабочее окружение Linux.

Используется, в частности, в:

- Fedora.
- RHEL.
- CentOS.
- Ubuntu.
- Debian.
- SUSE.

Другие рабочие окружения:

- KDE.
- XFCE.
- LXDE.
- Unity.

## Компоненты рабочего окружения

Рабочее окружение включает:

- **Session Manager** - запускает и поддерживает компоненты графического сеанса.
- **Window Manager** - управляет окнами, их расположением, перемещением и элементами управления.
- набор графических утилит.

## Настройка GNOME

### Фон и тема

Фон рабочего стола можно изменить через:

`ПКМ по рабочему столу -> Change Background`

**Тема** определяет внешний вид:

- окон.
- кнопок.
- полос прокрутки.
- других элементов интерфейса.

### gnome-tweaks

`gnome-tweaks` - расширенный инструмент настройки GNOME. Позволяет изменять параметры, которых нет в стандартных настройках. В некоторых современных системах часть функций перенесена в `gnome-extensions-app`. Запустить `gnome-tweaks` можно через:

```text
Alt + F2
```

Затем ввести:

```text
gnome-tweaks
```

## Работа с сеансом

### Блокировка экрана

Блокировка не останавливает работу системы, она делает так, что:

- программы продолжают работать.
- процессы продолжают выполняться.
- экран становится недоступен без пароля.

Чтобы быстро заблокировать экран, можно воспрользоваться гарячей клавишей:

```text
Super + L
```

`Super` - клавиша Windows.

### Смена пользователя

Linux является многопользовательской ОС. Каждый пользователь может иметь:

- собственную учётную запись.
- пароль.
- домашний каталог.
- собственные настройки и файлы.

Сеансы разных пользователей могут сохраняться независимо друг от друга.

### Выход, выключение и перезагрузка

Чтобы В GNOME перейти в меню завершения сеанса, нужно нажать:

`Power / Gear -> Log Out / Power Off / Restart`

Перед выходом или выключением необходимо сохранить данные.

### Режим сна

**Suspend (Sleep)** - режим низкого энергопотребления. При переходе в Suspend:

- состояние системы сохраняется в оперативной памяти.
- большая часть оборудования отключается.
- потребление энергии значительно уменьшается.
- сеанс можно быстро восстановить.

Для выхода из сна:

- пошевелить мышью.
- нажать клавишу клавиатуры.
- после этого ввести пароль.

## Запуск программ

В GNOME программы можно найти через:

- **Applications**;
- **Activities**;
- **Dash** в некоторых версиях Ubuntu.

Linux обычно поставляется с большим количеством программ и позволяет устанавливать дополнительные приложения из репозиториев.

## Программы по умолчанию

Программы по умолчанию используются для открытия определённых типов файлов или выполнения определённых задач. Их настройка находится тут:

```text
Settings -> Default Applications
```

или:

```text
Settings -> Details -> Default Applications
```

## Файловый менеджер Nautilus

**Nautilus (Files)** - файловый менеджер GNOME.

Используется для:

- просмотра файлов и каталогов.
- открытия файлов.
- поиска.
- копирования и перемещения файлов.
- удаления файлов.
- работы с каталогами.

Домашний каталог обычно открывается первым.

## Домашний каталог

Для каждого пользователя существует собственный **Home**.

Обычно он расположен в:

```text
/home/<username>
```

Например:

```text
/home/studentL
```

Внутри обычно находятся:

```text
Desktop
Documents
Downloads
Pictures
Videos
```

## Просмотр файлов

Nautilus поддерживает разные способы отображения файлов:

- **Icons** - значки.
- **List** - список.

Режим отображения можно менять на гарячие клавиши:

```text
Ctrl + 1 -> режим Icons
Ctrl + 2 -> режим List
```

Файлы можно сортировать по:

- имени.
- размеру.
- типу.
- дате изменения.

## Скрытые файлы

Скрытые файлы обычно начинаются с точки:

```text
.config
.bashrc
```

Чтобы увидить их в окне, достаточно включить отображение скрытых файлов в меню, или воспользоваться гарячей клавишей:

```text
Ctrl + H
```

## Поиск файлов

В Nautilus:

```text
Ctrl + F
```

Открывает поле поиска. Поиск выполняется рекурсивно в текущем каталоге.

## Переход к определённому пути

```text
Ctrl + L
```

Открывает поле Location, куда можно ввести или скопировать путь.

Например:

```text
/home/studentL/Documents
```

## Дополнительные фильтры

Поиск можно уточнять по:

- расположению.
- типу файла.
- нескольким критериям одновременно.

Для добавления дополнительного критерия используется кнопка `+`.

Например:

```text
File Type -> PDF
```

## Запуск Nautilus из терминала

В большинстве систем файловый менеджер можно открыть командой:

```bash
nautilus
```

# Редактирование файлов

Текстовый файл можно открыть двойным щелчком. В GNOME стандартным текстовым редактором является:

```text
gedit
```

Он используется для:

- редактирования текста.
- создания заметок.
- программирования.

## Удаление файлов

### Перемещение в корзину

В Nautilus, чтобы удалить файл или католог, нужно:

1. Выбрать файл или каталог.
2. Нажать `Ctrl + Delete`
3. Выбрать **Move to Trash**.

Файл перемещается в:

```text
.local/share/Trash/files/
```

### Полное удаление

Для полного удаления есть гарячая клавиша:

```text
Shift + Delete
```

Удаляет файл, обходя корзину.

Также можно:

```text
ПКМ по Trash → Empty Trash
```

### Важно

Не следует удалять собственный каталог:

```text
/home/<username>
```

В нём находятся пользовательские файлы и конфигурации системы и программ.

# Горячие клавиши GNOME / Nautilus

- `Super + L` - Заблокировать экран.
- `Ctrl + 1` - Просмотр файлов значками.
- `Ctrl + 2` - Просмотр файлов списком.
- `Ctrl + H` - Показать/скрыть скрытые файлы.
- `Ctrl + F` - Поиск файлов.
- `Ctrl + L`-  Перейти к указанному пути.
- `Ctrl + Delete` - Переместить файл в корзину.
- `Shift + Delete` - Удалить файл без корзины.
- `Alt + F2` - Запуск команды/программы.
