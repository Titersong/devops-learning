# Текстовые редакторы

## Зачем нужны текстовые редакторы

В Linux текстовые редакторы используются для:

- редактирования конфигурационных файлов.
- написания Bash-скриптов.
- работы с исходным кодом.
- создания обычных текстовых файлов.

Важно отличать **текстовый редактор** от текстового процессора вроде LibreOffice Writer. Текстовые процессоры добавляют форматирование и служебную информацию, поэтому не подходят для редактирования системных конфигурационных файлов. Основные редакторы Linux:

```text
nano
gedit
vi / vim
emacs
```

## Создание файла без редактора

Иногда небольшой текстовый файл удобнее создать прямо из командной строки.

### echo

Создать или перезаписать файл:

```bash
echo "line one" > myfile
```

Добавить строку в конец:

```bash
echo "line two" >> myfile
```

Важно:

```text
>  -> перезаписать файл
>> -> добавить данные в конец файла
```

### cat и Here Document

Можно передать сразу несколько строк:

```bash
cat << EOF > myfile
line one
line two
line three
EOF
```

Такой способ особенно полезен в Bash-скриптах.

## nano

`nano` - простой терминальный текстовый редактор. Открыть файл:

```bash
nano filename
```

Если файла нет, он будет создан. Основные комбинации:

```text
Ctrl + G -> помощь
Ctrl + O -> сохранить файл
Ctrl + X -> выйти
Ctrl + R -> вставить содержимое другого файла
Ctrl + C -> показать положение курсора
```

Команды отображаются в нижней части окна, поэтому `nano` удобен для начинающих.

## gedit

`gedit` - графический текстовый редактор среды GNOME. Он похож на обычный графический Блокнот, но поддерживает дополнительные возможности и плагины. Запуск:

```bash
gedit filename
```

Для работы `gedit` требуется графическая среда.

# vi и vim

`vi` - один из стандартных текстовых редакторов UNIX/Linux. Во многих современных системах фактически используется:

```text
vim = Vi Improved
```

Даже если основным редактором является `nano`, базовые команды `vi` стоит знать, потому что он доступен практически на всех Linux-системах. Открыть файл:

```bash
vi filename
```

Для обучения можно использовать встроенный учебник:

```bash
vimtutor
```

## Режимы vi

Особенность `vi` - наличие нескольких режимов.

### Command Mode

Режим по умолчанию. В этом режиме клавиши воспринимаются как команды:

```text
удалить
копировать
переместить курсор
перейти в другой режим
```

### Insert Mode

Используется для непосредственного ввода текста. Перейти из Command Mode:

```text
i
```

Вернуться:

```text
Esc
```

### Line Mode

Используется для команд работы с файлом. Перейти:

```text
:
```

Например:

```text
:w
:q
:wq
```

Вернуться в Command Mode:

```text
Esc
```

Упрощённо:

```text
Command Mode
   ↓ i
Insert Mode
   ↓ Esc
Command Mode
   ↓ :
Line Mode
```

## Основные команды vi

## Сохранение и выход

Сохранить файл:

```text
:w
```

Сохранить и выйти:

```text
:wq
```

или:

```text
:x
```

Выйти:

```text
:q
```

Выйти без сохранения:

```text
:q!
```

## Навигация в vi

Можно использовать стрелки или классические клавиши:

```text
h -> влево
j -> вниз
k -> вверх
l -> вправо
```

Полезные команды:

```text
0  -> начало строки
$  -> конец строки
w  -> следующее слово
G  -> конец файла
1G -> начало файла
nG -> перейти к строке n
```

Например:

```text
25G
```

перейдёт к строке 25.

## Поиск в vi

Поиск вперёд:

```text
/pattern
```

Поиск назад:

```text
?pattern
```

Следующее совпадение:

```text
n
```

Предыдущее:

```text
N
```

## Редактирование текста в vi

Перейти к вводу текста:

```text
i -> вставить перед курсором
a -> вставить после курсора
o -> создать новую строку ниже
O -> создать новую строку выше
```

Удаление:

```text
x  -> удалить символ
dw -> удалить слово
dd -> удалить строку
D  -> удалить остаток строки
```

Отмена последней операции:

```text
u
```

Копирование строки:

```text
yy
```

Вставка скопированного:

```text
p
```

Например:

```text
5dd
```

удалит пять строк.

## Внешние команды в vi

Из `vi` можно запускать команды оболочки. Например:

```text
:! command
```

Символ:

```text
%
```

представляет текущий редактируемый файл. Например:

```text
:! wc %
```

запустит `wc` для текущего файла.

## emacs

`emacs` - ещё один мощный редактор, являющийся альтернативой `vi`. В отличие от `vi`, он не использует отдельные режимы Command и Insert. Управление выполняется комбинациями:

```text
Ctrl
Alt / Meta
```

Запуск:

```bash
emacs filename
```

Основные команды:

```text
Ctrl + X, Ctrl + S -> сохранить файл
Ctrl + X, Ctrl + C -> выйти
Ctrl + X, Ctrl + W -> сохранить под другим именем
```

Встроенный учебник:

```text
Ctrl + H
затем
t
```

## Навигация в emacs

```text
Ctrl + N -> вниз
Ctrl + P -> вверх
Ctrl + F -> вправо
Ctrl + B -> влево
Ctrl + A -> начало строки
Ctrl + E -> конец строки
```

## Поиск

```text
Ctrl + S -> искать вперёд
Ctrl + R -> искать назад
```

## Сравнение редакторов

| Редактор | Особенность |
|---|---|
| `nano` | простой терминальный редактор |
| `gedit` | простой графический редактор |
| `vi/vim` | мощный стандартный терминальный редактор |
| `emacs` | мощный редактор с большим количеством возможностей |

## Что важно запомнить

1. Для системных файлов нужны обычные текстовые редакторы, а не текстовые процессоры.
2. `>` перезаписывает файл, а `>>` добавляет данные в конец.
3. `nano` - простой редактор для быстрой работы в терминале.
4. `Ctrl+O` сохраняет файл в nano, `Ctrl+X` выходит.
5. `vi/vim` доступен практически на всех Linux-системах.
6. Для изучения vim существует команда `vimtutor`.
7. В vi есть режимы Command, Insert и Line.
8. `i` переводит vi в режим ввода, `Esc` возвращает в Command Mode.
9. `:w` сохраняет файл.
10. `:wq` сохраняет и выходит.
11. `:q!` выходит без сохранения изменений.
12. `/pattern` используется для поиска текста в vi.
13. `dd` удаляет строку, `yy` копирует её, `p` вставляет.
14. `emacs` не использует режимы vi и управляется в основном комбинациями Ctrl и Meta.
