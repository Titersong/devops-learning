# Конфигурация системы через графический интерфейс

## Системные настройки

В Linux основные параметры системы можно менять через **System Settings**. Через настройки можно управлять:

- дисплеями.
- клавиатурой.
- пользователями.
- сетью.
- датой и временем.
- другими параметрами рабочего стола.

В GNOME расположение пунктов меню может немного отличаться между дистрибутивами и версиями системы.

## gnome-tweaks

Некоторые дополнительные настройки GNOME отсутствуют в стандартном меню. Для них используется **gnome-tweaks**. С его помощью можно:

- менять тему.
- управлять шрифтами.
- изменять раскладку клавиатуры.
- настраивать автозапуск программ.
- работать с расширениями GNOME.

Для расширений также может использоваться отдельная программа **gnome-extensions-app**.

## Настройки дисплея

Раздел **Displays** позволяет:

- менять разрешение.
- настраивать несколько мониторов.
- выбирать расположение экранов.
- включать зеркальное отображение.

Обычно Linux автоматически определяет подходящее разрешение. Для некоторых видеокарт могут существовать отдельные программы настройки драйвера.

## Дата и время

Linux использует **UTC** для внутреннего отсчёта времени. Отображаемое пользователю время зависит от выбранного часового пояса. Настройки даты и времени можно изменить через:

```text
System Settings -> Date & Time
```

## NTP

**NTP (Network Time Protocol)** - протокол автоматической синхронизации времени через серверы в интернете. В большинстве дистрибутивов NTP уже настроен, поэтому обычно достаточно просто включить автоматическую синхронизацию.

## Настройка сети

### NetworkManager

**NetworkManager** - система для управления сетевыми подключениями. Он позволяет работать с:

- Ethernet.
- Wi-Fi.
- мобильными сетями.
- VPN.

Обычно NetworkManager автоматически обнаруживает подключения и применяет нужные настройки.

### DHCP

Для большинства обычных сетей используется:

**DHCP** - протокол, который автоматически выдаёт компьютеру сетевые параметры. Благодаря этому обычно не нужно вручную вводить:

- IP-адрес.
- шлюз.
- другие параметры сети.

При необходимости можно настроить статический адрес вручную.

### MAC-адрес

**MAC-адрес** - уникальный идентификатор сетевого интерфейса. Он обычно представлен в шестнадцатеричном виде и относится к конкретной сетевой карте.

### Wi-Fi

NetworkManager позволяет:

- просматривать доступные сети.
- подключаться к Wi-Fi.
- сохранять пароль.
- автоматически подключаться к известным сетям.
- изменять параметры подключения.

### VPN

NetworkManager также может управлять VPN-подключениями. В курсе упоминаются:

- IPSec.
- OpenConnect.
- PPTP.
- OpenVPN.

Для некоторых типов VPN может потребоваться установка дополнительного пакета.

## Установка и обновление программ

### Пакеты

Программное обеспечение Linux распространяется в виде **пакетов**. Пакет может содержать:

- программу.
- библиотеку.
- системную утилиту.
- драйвер.
- компонент ядра.
- другие части системы.

Пакеты могут зависеть друг от друга. Такие связи называются **зависимостями**. Менеджеры пакетов высокого уровня умеют автоматически находить и устанавливать необходимые зависимости.

### Debian / Ubuntu

Базовый менеджер пакетов:

```text
dpkg
```

`dpkg` может устанавливать и удалять пакеты, но сам не занимается полноценным скачиванием пакетов и автоматическим разрешением зависимостей. Для более удобной работы используется:

```text
APT
```

Основные интерфейсы:

```text
apt
apt-get
```

Также могут использоваться графические программы:

```text
Synaptic
GNOME Software
Ubuntu Software Center
```

### Red Hat

Семейство Red Hat использует формат:

```text
RPM
```

Для управления пакетами на более высоком уровне применяются:

```text
dnf
yum
```

`dnf` используется в современных системах, при этом сохраняется совместимость со многими командами `yum`.

### SUSE

Семейство SUSE также использует RPM. Основной менеджер высокого уровня:

```text
zypper
```

Также используется графический инструмент:

```text
YaST
```

YaST позволяет устанавливать, удалять и обновлять программы через графический интерфейс.
