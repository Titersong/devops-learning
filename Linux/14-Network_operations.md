# Сетевые операции

## Основы компьютерных сетей

**Компьютерная сеть** - группа устройств, соединённых между собой для обмена данными и совместного использования ресурсов. Сети позволяют:

- обмениваться информацией между компьютерами.
- предоставлять общий доступ к файлам и устройствам.
- подключаться к удалённым серверам.
- использовать интернет-сервисы.

Передача информации осуществляется небольшими частями - **пакетами (packets)**. Пакеты содержат данные и служебную информацию, необходимую для их доставки.

## IP-адресация

## IP-адрес

**IP-адрес (Internet Protocol Address)** - логический сетевой адрес, используемый для идентификации устройства и доставки пакетов через сеть. Существуют две основные версии IP:

| | IPv4 | IPv6 |
|---|---|---|
| Размер адреса | 32 бита | 128 бит |
| Количество адресов | ~4,3 млрд | ~3,4 × 10³⁸ |
| Пример | `192.168.1.10` | `2001:db8::1` |

IPv6 был создан для преодоления ограниченного количества адресов IPv4.

## Структура IPv4

IPv4 состоит из четырёх октетов.

**Октет** - 8 бит, значение от 0 до 255. Например:

```text
192.168.1.10
```

В адресе выделяют:

```text
Network ID -> идентификатор сети
Host ID    -> идентификатор устройства в сети
```

## Классы IPv4

| Класс | Часть сети | Часть хоста |
|---|---|---|
| A | Первый октет | Последние три |
| B | Первые два октета | Последние два |
| C | Первые три октета | Последний октет |

Также существуют:

- **Класс D** - многоадресная передача (Multicast).
- **Класс E** - зарезервированные адреса.

Классовая модель исторически важна для понимания IPv4. В современных сетях используются также маски подсети и CIDR, которые позволяют гибче разделять адреса.

## NAT

**NAT (Network Address Translation)** - технология преобразования сетевых адресов. Она позволяет нескольким устройствам локальной сети использовать один внешний публичный IP-адрес. Например:

```text
                                                             192.168.1.2
                                                             /
                                                            /
 Internet -- Public IP Address -- Router NAT -- Local Network -- 192.168.1.3
                                                            \
                                                             \
                                                             192.168.1.4
```

Устройства имеют собственные локальные IP-адреса, но выходят в интернет через общий внешний адрес маршрутизатора.

## Назначение IP-адресов

Существует два способа назначения IP-адресов.

## Static IP

**Статический IP** - адрес, заданный вручную. Он остаётся неизменным, пока его конфигурацию не изменят.

## DHCP

**DHCP (Dynamic Host Configuration Protocol)** - протокол автоматической выдачи сетевых параметров. С его помощью устройство может автоматически получить IP-адрес и другие необходимые параметры сети. Это избавляет от необходимости вручную настраивать каждое устройство.

## DNS и имена хостов

## DNS

**DNS (Domain Name System)** - система преобразования доменных имён в IP-адреса. Например:

```text
            DNS
example.com -> IP address
```

Благодаря DNS пользователю не нужно запоминать числовые адреса серверов.

## Hostname

**Hostname** - сетевое имя компьютера. Посмотреть имя своей машины:

```bash
hostname
```

## localhost

Специальное имя:

```text
localhost
```

обычно соответствует адресу:

```text
127.0.0.1
```

Этот адрес обозначает текущую машину - соединение с самой собой.

## Настройка сети в Linux

## Сетевые интерфейсы

**Network Interface** - интерфейс, через который компьютер подключается к сети. Он может быть:

- физическим - Ethernet или Wi-Fi.
- виртуальным - программный сетевой интерфейс.

Linux позволяет использовать несколько сетевых интерфейсов одновременно.

## NetworkManager

**NetworkManager** - система управления сетевыми подключениями Linux. Она используется для настройки сетевых интерфейсов и подключений. Основные инструменты:

```text
nmtui -> текстовый интерфейс настройки сети
nmcli -> управление сетью через командную строку
```

В разных дистрибутивах могут использоваться разные конфигурационные файлы и инструменты.

## Команда ip

`ip` - основной современный инструмент просмотра и управления сетевыми параметрами Linux. Просмотр IP-адресов:

```bash
ip addr show
```

Показывает сетевые интерфейсы и назначенные им IP-адреса. Просмотр маршрутов:

```bash
ip route show
```

Показывает таблицу маршрутизации системы. Она определяет, куда Linux должен отправлять сетевые пакеты.

## ifconfig

`ifconfig` - более старая утилита управления сетевыми интерфейсами. Во многих современных дистрибутивах она заменена инструментом `ip` и может не быть установлена по умолчанию.

## Диагностика сети

## ping

`ping` используется для проверки ответа удалённого сетевого узла.

```bash
ping example.com
```

Ограничить количество запросов:

```bash
ping -c 4 example.com
```

Команда отправит четыре запроса и покажет результаты. Для остановки непрерывного `ping`:

```text
Ctrl + C
```

## Маршрутизация

**Routing** - процесс определения пути передачи пакетов между сетями. Linux хранит информацию о маршрутах в таблице маршрутизации. Посмотреть её:

```bash
ip route
```

В таблице можно увидеть маршруты к сетям и шлюз, через который передаётся трафик. Для управления маршрутами используются:

```text
ip route add -> добавить маршрут
ip route del -> удалить маршрут
```

## traceroute

`traceroute` показывает путь, по которому пакеты проходят к удалённому узлу.

```bash
traceroute example.com
```

Команда полезна для поиска проблем и задержек между сетевыми узлами.

## Другие сетевые инструменты

| Команда | Назначение |
|---|---|
| `ethtool` | информация и настройки сетевого интерфейса |
| `netstat` | соединения и сетевая статистика |
| `nmap` | сканирование сетевых портов |
| `tcpdump` | перехват и анализ сетевого трафика |
| `iptraf` | мониторинг сетевого трафика |
| `mtr` | объединяет возможности ping и traceroute |
| `dig` | диагностика DNS |

Например, проверить разрешение доменного имени:

```bash
dig example.com
```

## Работа с веб-ресурсами

Linux позволяет получать веб-ресурсы не только через графические браузеры, но и из терминала. Для этого используются:

```text
wget
curl
```

## wget

`wget` - утилита для скачивания файлов через сеть.

```bash
wget https://example.com/file.zip
```

Используется для:

- загрузки отдельных файлов.
- скачивания больших файлов.
- загрузки нескольких ресурсов.
- рекурсивного скачивания.

Удобна для автоматизированных загрузок.

## curl

`curl` - инструмент передачи данных по сетевым протоколам, в том числе HTTP и HTTPS. Получить содержимое веб-страницы:

```bash
curl https://example.com
```

Сохранить содержимое в файл:

```bash
curl -o page.html https://example.com
```

`curl` также полезен для работы с веб-сервисами и сетевыми запросами из скриптов.

### Разница между wget и curl

```text
wget -> в основном удобен для скачивания файлов
curl -> удобен для выполнения сетевых запросов и получения данных
```

## Передача файлов между компьютерами

## FTP

**FTP (File Transfer Protocol)** - протокол передачи файлов между клиентом и сервером. FTP является старым протоколом и не обеспечивает шифрование обычных соединений, поэтому не подходит для передачи конфиденциальных данных.

## SFTP

**SFTP (SSH File Transfer Protocol)** - протокол безопасной передачи файлов через SSH. В отличие от обычного FTP, SFTP использует защищённое соединение. Пример подключения:

```bash
sftp user@server
```

## SSH

**SSH (Secure Shell)** - протокол для безопасного удалённого доступа и выполнения команд на другом компьютере. Он широко используется для администрирования Linux-серверов. Подключение по SSH происходит так:

```bash
ssh user@server
```

Например:

```bash
ssh student@192.168.1.100
```

После подключения можно работать с удалённой системой через терминал.

## Запуск удалённой команды

SSH позволяет выполнить отдельную команду без полноценной интерактивной работы в удалённой оболочке.

```bash
ssh user@server "uptime"
```

Команда `uptime` выполнится на удалённом сервере.

## Авторизация SSH

SSH поддерживает:

- вход с паролем.
- аутентификацию с помощью криптографических ключей.

SSH-ключи позволяют безопасно организовать доступ без постоянного ввода пароля учётной записи.

## SCP

**SCP (Secure Copy)** - утилита копирования файлов между компьютерами с использованием SSH. Копирование на сервер:

```bash
scp file.txt user@server:/home/user/
```

Локальный файл будет отправлен на удалённую машину. Копирование с сервера:

```bash
scp user@server:/home/user/file.txt .
```

Файл будет скопирован с удалённой машины в текущий локальный каталог.

## Что важно запомнить

1. Сети позволяют устройствам обмениваться данными и использовать общие ресурсы.
2. IP-адрес используется для сетевой адресации и доставки пакетов.
3. IPv4 использует 32 бита, IPv6 - 128 бит.
4. NAT позволяет нескольким устройствам использовать один внешний IP-адрес.
5. DHCP автоматически назначает сетевые параметры.
6. DNS преобразует доменные имена в IP-адреса.
7. `localhost` обозначает текущую машину, обычно `127.0.0.1`.
8. `ip addr show` показывает адреса сетевых интерфейсов.
9. `ip route show` показывает маршруты передачи пакетов.
10. `ping` проверяет ответ сетевого узла.
11. `traceroute` помогает анализировать путь пакетов.
12. `dig` используется для проверки DNS.
13. `wget` предназначен для загрузки файлов, `curl` - для сетевых запросов и передачи данных.
14. Обычный FTP не шифрует соединение.
15. SSH обеспечивает безопасный удалённый доступ к системе.
16. SCP и SFTP используются для безопасной передачи файлов через SSH.
