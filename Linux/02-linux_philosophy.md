# Философия и концепции Linux

## Краткая история Linux

Linux появился в 1991 году как проект Линуса Торвальдса по созданию собственного ядра операционной системы. Позже Linux был лицензирован под GPL, что позволило разработчикам со всего мира участвовать в его развитии. Ядро Linux вместе с другими системными компонентами стало основой полноценных операционных систем - **дистрибутивов Linux**.

## Философия Linux

Linux был во многом вдохновлён UNIX, но сам UNIX не является. Основные особенности Linux:

- открытый исходный код.
- многозадачность.
- многопользовательская работа.
- встроенные сетевые возможности.
- использование фоновых сервисных процессов - **демонов (daemons)**.
- иерархическая файловая система с корнем `/`.

В Linux многие компоненты системы представлены как файлы или файлоподобные объекты. Это относится не только к обычным данным, но также к устройствам, процессам и другим системным объектам.

## Сообщество Linux

Linux развивается международным сообществом:

- разработчиков.
- системных администраторов.
- пользователей.
- компаний и поставщиков ПО.

Для общения и совместной разработки используются форумы, GitHub, GitLab, списки рассылки, конференции и другие площадки.

## Основные термины Linux

- **Ядро (Kernel)** - центральная часть операционной системы. Управляет процессором, памятью, устройствами и позволяет программам взаимодействовать с оборудованием.
- **Дистрибутив (Distribution)** - готовая операционная система на основе ядра Linux, которая дополнительно содержит программы, библиотеки, утилиты и систему управления пакетами. Примеры: Ubuntu, Fedora, Debian.
- **Загрузчик (Bootloader)** - программа, которая запускается при включении компьютера и загружает операционную систему. В Linux часто используется GRUB.
- **Служба (Service)** - программа или процесс, работающий в фоне и выполняющий определённую системную задачу, например работу веб-сервера или SSH.
- **Файловая система (File System)** - способ организации и хранения файлов и каталогов на диске. В Linux всё начинается от корневого каталога `/`.
- **X Window System** - система, предоставляющая базовые возможности для отображения графического интерфейса и работы с окнами в Linux.
- **Среда рабочего стола (Desktop Environment)** - готовый графический интерфейс Linux: рабочий стол, панели, меню, настройки и стандартные приложения. Например, GNOME или KDE Plasma.
- **Командная строка (Command Line)** - текстовый интерфейс, через который пользователь вводит команды для управления системой.
- **Shell** - программа, которая принимает введённые в командной строке команды и выполняет их. Один из самых распространённых Shell в Linux - Bash.

## Ядро и дистрибутив

**Ядро Linux** - центральная часть операционной системы. Самого ядра недостаточно для полноценной рабочей системы. **Дистрибутив Linux** состоит из:

1. ядра Linux.
2. системных утилит.
3. библиотек.
4. программ.
5. средств управления пользователями.
6. системы управления пакетами.
7. средств обновления и настройки.

Разные дистрибутивы могут использовать разные версии ядра и разные наборы программ. Некоторые дистрибутивы также предоставляют коммерческую техническую поддержку и собственные сервисы обновления.

1. Linux появился как ядро, созданное Линусом Торвальдсом.
2. Linux был вдохновлён UNIX, но не является UNIX.
3. Linux - многозадачная и многопользовательская система.
4. Корнем файловой системы является `/`.
5. Многие системные компоненты Linux представлены как файлы или файлоподобные объекты.
6. Фоновые сервисные процессы называются **демонами (daemons)**.
7. Ядро Linux - только центральная часть системы.
8. Дистрибутив = ядро Linux + программы, библиотеки, утилиты и средства управления системой.
9. Разные дистрибутивы могут использовать разные версии ядра и наборы программ.
