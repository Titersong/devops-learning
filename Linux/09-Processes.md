# Процессы

## Что такое процесс

**Процесс** - это выполняющийся экземпляр программы или задачи. Программа и процесс - не одно и то же:

```text
Программа -> файл с кодом
Процесс -> запущенный экземпляр этой программы
```

Одна программа может одновременно создавать несколько процессов или потоков. Процессы используют системные ресурсы:

- процессор (CPU).
- оперативную память.
- диски.
- сеть.
- другие устройства.

Ядро Linux распределяет эти ресурсы между процессами.

## Типы процессов

### Интерактивные процессы

Запускаются пользователем через терминал или графический интерфейс. Примеры:

```text
bash
firefox
top
```

### Пакетные процессы

Запускаются автоматически или планируются заранее, после чего работают без взаимодействия с пользователем.

### Демоны (Daemons)

Фоновые системные процессы, которые обычно работают постоянно и ожидают запросов (например, сервер). Примеры:

```text
sshd
httpd
```

### Потоки (Threads)

Отдельные задачи внутри одного процесса. Потоки одного процесса могут совместно использовать память и другие ресурсы. Один процесс может иметь несколько потоков.

### Потоки ядра

Служебные задачи самого ядра Linux, которые управляют внутренней работой системы.

## Состояния процессов

Процесс может находиться в разных состояниях.

### Running

Процесс:

- выполняется на CPU.
- или ожидает своей очереди для выполнения.

### Sleeping

Процесс временно ждёт какого-либо события или ресурса. Например:

```text
ввод пользователя
операцию с диском
сетевые данные
```

### Zombie

Процесс уже завершился, но информация о нём ещё остаётся в таблице процессов, потому что родительский процесс ещё не обработал его завершение.

## Идентификаторы процессов

Каждому процессу Linux назначается уникальный:

```text
PID
```

**PID (Process ID)** - идентификатор процесса.

Например:

```text
PID 1
```

Обычно принадлежит процессу инициализации системы. Другие идентификаторы:

- **PPID** - PID родительского процесса.
- **TID** - идентификатор отдельного потока.

## Пользователи и процессы

Каждый процесс связан с пользователем и группой. Основные идентификаторы:

```text
UID -> пользователь
GID -> группа
```

Более подробно существуют:

- `RUID` - пользователь, запустивший процесс.
- `EUID` - пользователь, права которого использует процесс.
- `RGID` - исходная группа.
- `EGID` - группа, права которой используются.

В большинстве обычных задач достаточно понимать `UID` и `GID`.

## Завершение процесса

Для завершения процесса используется:

```bash
kill <PID>
```

Для принудительного завершения:

```bash
kill -9 <PID>
```

или:

```bash
kill -SIGKILL <PID>
```

Обычный пользователь может завершать свои процессы. Для управления процессами других пользователей требуются административные права.

## Приоритет процессов

Linux позволяет задавать процессам разный приоритет.

Для этого используется значение:

```text
nice
```

Диапазон:

```text
-20 -> самый высокий приоритет
+19 -> самый низкий приоритет
```

То есть, чем меньше `nice`, тем выше приоритет, а чем больше `nice`, тем ниже приоритет. Процесс с высоким значением `nice` чаще уступает процессорное время другим процессам.

## Load Average

**Load Average** показывает среднюю нагрузку системы. Посмотреть её можно через:

```bash
uptime
```

```bash
w
```

```bash
top
```

Обычно выводятся три числа:

```text
за 1 минута
за 5 минут
за 15 минут
```

Например:

```text
0.45 0.17 0.12
```

Для системы с одним CPU значение `1.00` означает примерно полную загрузку. Для системы с несколькими процессорами/ядрами нагрузку нужно оценивать относительно их количества. Например, для четырёх CPU `load average 4.00` соответствует полной общей загрузке системы. Кратковременные пики нагрузки обычно не являются проблемой. Более важно смотреть на показатели за 5 и 15 минут.

## Foreground и Background

По умолчанию команда запускается на **переднем плане (foreground)**. Пока она работает, текущая оболочка занята. Запустить команду в фоне:

```bash
command &
```

Например:

```bash
updatedb &
```

## Управление задачами

Приостановить текущую foreground-задачу:

```text
Ctrl + Z
```

Завершить текущую задачу:

```text
Ctrl + C
```

Продолжить задачу в фоне:

```bash
bg
```

Вернуть задачу на передний план:

```bash
fg
```

Посмотреть фоновые задачи:

```bash
jobs
```

Показать также PID:

```bash
jobs -l
```

## Просмотр процессов

### ps

`ps` показывает информацию о запущенных процессах. Без параметров:

```bash
ps
```

показывает процессы текущей оболочки. Все процессы системы:

```bash
ps -ef
```

Популярный BSD-вариант:

```bash
ps aux
```

Процессы определённого пользователя:

```bash
ps -u username
```

Также `ps` может отображать информацию о потоках и различные дополнительные атрибуты процессов.

### pstree

Показывает процессы в виде дерева:

```bash
pstree
```

Похожа по виду на `tree`, которая показывает дерево каталогов.

## top

`top` показывает процессы и состояние системы **в реальном времени**. Запускается с команды:

```bash
top
```

Выход:

```text
q
```

`top` показывает:

- uptime системы.
- количество пользователей.
- load average.
- количество процессов.
- состояния процессов.
- использование CPU.
- использование RAM.
- использование swap.
- процессы, потребляющие больше всего ресурсов.

## Основные поля процесса в top

```text
PID      -> ID процесса
USER     -> владелец
PR       -> приоритет
NI       -> nice
%CPU     -> использование CPU
%MEM     -> использование памяти
TIME+    -> время работы CPU
COMMAND  -> команда
```

Также отображаются:

```text
VIRT -> виртуальная память
RES  -> физическая память
SHR  -> разделяемая память
```

## Полезные клавиши top

```text
q -> выход
k -> завершить процесс
r -> изменить приоритет
m -> показать/скрыть информацию о памяти
t -> показать/скрыть информацию о CPU
```

## RAM и Swap

`top` также показывает использование:

```text
RAM
Swap
```

**Swap** - место на диске, которое система может использовать как дополнительную память. Доступ к диску намного медленнее RAM, поэтому активное использование swap может снижать производительность системы.

## Планирование выполнения команд

### at

`at` используется для **однократного запуска команды в будущем**. То есть:

```text
выполнить команду один раз в указанное время
```

Подходит для разовых задач.

### cron

`cron` используется для **регулярного автоматического выполнения команд**. Например:

```text
делать backup каждый день
очищать временные файлы раз в неделю
запускать скрипт каждый час
```

Редактировать пользовательский cron:

```bash
crontab -e
```

Формат записи:

```text
MIN HOUR DOM MON DOW COMMAND
```

Где:

```text
MIN  -> минуты (0–59)
HOUR -> часы (0–23)
DOM  -> день месяца (1–31)
MON  -> месяц (1–12)
DOW  -> день недели (0–6)
```

Например:

```cron
30 08 10 06 * /home/sysadmin/full-backup
```

Означает:

```text
08:30
10 июня
запустить /home/sysadmin/full-backup
```

Символ:

```text
*
```

Означает любое значение. Например:

```cron
* * * * * command
```

Запускает команду каждую минуту.

### sleep

`sleep` временно приостанавливает выполнение команды или скрипта. Синтаксис:

```bash
sleep NUMBER
```

Например:

```bash
sleep 10
```

Подождать 10 секунд. Также можно использовать:

```text
s -> секунды
m -> минуты
h -> часы
d -> дни
```

Например:

```bash
sleep 5m
```

Подождать 5 минут. Важно различать:

```text
sleep → подождать определённое время и продолжить
at    → запустить задачу в определённое время в будущем
cron  → регулярно запускать задачу
```

# Основные команды раздела

| Команда | Назначение |
|---|---|
| `ps` | показать процессы |
| `ps -ef` | показать все процессы |
| `ps aux` | подробный список процессов |
| `pstree` | показать дерево процессов |
| `top` | мониторинг процессов в реальном времени |
| `kill` | завершить процесс |
| `jobs` | показать фоновые задачи |
| `bg` | продолжить задачу в фоне |
| `fg` | вернуть задачу на передний план |
| `uptime` | показать uptime и load average |
| `at` | однократно запустить задачу в будущем |
| `crontab -e` | настроить регулярные задачи |
| `sleep` | приостановить выполнение |

# Что важно запомнить

1. Процесс - это выполняющийся экземпляр программы или задачи.
2. Каждый процесс имеет уникальный `PID`.
3. `PPID` указывает на родительский процесс.
4. Процесс может состоять из нескольких потоков.
5. Демоны - фоновые процессы, которые обычно работают постоянно.
6. `nice` определяет приоритет процесса: чем меньше значение, тем выше приоритет.
7. `ps` показывает список процессов.
8. `pstree` показывает связи между процессами.
9. `top` позволяет наблюдать процессы и ресурсы системы в реальном времени.
10. `kill` используется для завершения процесса.
11. `Ctrl+C` завершает текущую задачу, а `Ctrl+Z` приостанавливает её.
12. `&`, `bg`, `fg` и `jobs` используются для работы с фоновыми задачами.
13. Load Average показывает среднюю нагрузку системы за 1, 5 и 15 минут.
14. `at` используется для однократного запуска задачи в будущем.
15. `cron` используется для регулярного запуска задач.
16. `sleep` приостанавливает выполнение на определённое время.
