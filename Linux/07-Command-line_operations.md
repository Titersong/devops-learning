# Операции командной строки

## Командная строка Linux

Командная строка - один из основных способов управления Linux. Она особенно важна для системного администрирования, потому что позволяет:

- выполнять практически любые системные задачи.
- автоматизировать действия с помощью скриптов.
- работать с удалёнными серверами.
- использовать систему без графического интерфейса.
- одинаково работать в разных дистрибутивах Linux.

## Терминал и Shell

**Эмулятор терминала** - это программа, которая предоставляет окно для работы с командной строкой внутри графической среды. Примеры:

```text
gnome-terminal
konsole
xterm
terminator
```

**Shell** - это программа, которая принимает введённые команды и выполняет их.

Чаще всего используется:

```text
bash
```

Если проще:

```text
Terminal -> предоставляет окно
Shell -> обрабатывает команды
```

# Структура команды

Обычно команда состоит из:

```text
команда + параметры + аргументы
```

Например:

```bash
ls -a /home
```

Здесь:

```text
ls    -> команда
-a    -> параметр
/home -> аргумент
```

Параметры изменяют поведение команды и обычно начинаются с:

```text
-
--
```

Например:

```bash
-a
--help
```

Не каждая команда обязательно имеет параметры или аргументы.

## Получение прав администратора

### sudo

`sudo` позволяет выполнить отдельную команду с повышенными правами, обычно с правами пользователя `root`. Пример:

```bash
sudo systemctl restart ssh
```

При первом использовании обычно необходимо ввести пароль текущего пользователя.

### su

`su` позволяет переключиться на другого пользователя. Без указания имени:

```bash
su
```

обычно выполняется переключение на `root`. У обычного пользователя приглашение командной строки часто заканчивается:

```text
$
```

у `root`:

```text
#
```

Для повседневного администрирования обычно предпочтительнее использовать `sudo`, а не постоянно работать от `root`.

## Виртуальные терминалы

**Virtual Terminal (VT)** - полноэкранная текстовая консоль Linux, работающая независимо от графической среды. Переключиться из GUI можно комбинацией:

```text
Ctrl + Alt + F1...F12
```

Конкретные номера могут зависеть от дистрибутива. Виртуальные терминалы особенно полезны, если графическая среда зависла или перестала работать.

## Вход на удалённый сервер

Для удалённого подключения используется SSH:

```bash
ssh user@server
```

Например:

```bash
ssh student@remote-server.com
```

SSH позволяет безопасно получить командную строку удалённого Linux-компьютера. Для авторизации можно использовать:

- пароль.
- SSH-ключ.

## Выключение и перезагрузка

Корректно выключать или перезагружать Linux следует системными командами. 

Выключение:

```bash
sudo shutdown -h now
```

Перезагрузка:

```bash
sudo shutdown -r now
```

Также используются:

```bash
sudo poweroff
sudo reboot
```

Можно запланировать выключение:

```bash
sudo shutdown -h 10:00
```

Правильное завершение работы важно, чтобы избежать повреждения файловой системы или потери данных.

## Поиск расположения программ

### which

Показывает путь к программе, которая будет выполнена:

```bash
which diff
```

Например:

```text
/usr/bin/diff
```

### whereis

Ищет программу в более широком наборе системных каталогов:

```bash
whereis diff
```

Также может показать связанные man-страницы и другие файлы программы.

## Навигация по файловой системе

### pwd

Показывает текущий рабочий каталог:

```bash
pwd
```

### cd

Переход в каталог:

```bash
cd /home/user/Documents
```

Перейти в домашний каталог:

```bash
cd
```

или:

```bash
cd ~
```

Перейти на уровень выше:

```bash
cd ..
```

Вернуться в предыдущий каталог:

```bash
cd -
```

### ls

Показывает содержимое каталога:

```bash
ls
```

Показать также скрытые файлы:

```bash
ls -a
```

В Linux скрытыми считаются файлы и каталоги, имя которых начинается с:

```text
.
```

Например:

```text
.bashrc
.git
```

### tree

Показывает структуру каталогов в виде дерева:

```bash
tree
```

Только каталоги:

```bash
tree -d
```

## Абсолютные и относительные пути

### Абсолютный путь

Начинается от корня файловой системы:

```text
/
```

Например:

```text
/home/user/Documents/file.txt
```

Абсолютный путь всегда начинается с `/`.

### Относительный путь

Указывается относительно текущего каталога. Например:

```bash
cd Documents
```

Полезные обозначения:

```text
.  -> текущий каталог
.. -> родительский каталог
~  -> домашний каталог пользователя
```

## Просмотр файлов

### cat

Показывает содержимое небольшого файла:

```bash
cat file.txt
```

Также может объединять содержимое файлов.

### tac

Показывает файл в обратном порядке - начиная с последней строки:

```bash
tac file.txt
```

### less

Удобен для просмотра больших файлов:

```bash
less file.txt
```

Позволяет:

- прокручивать файл.
- перемещаться назад и вперёд.
- искать текст.

Поиск вперёд:

```text
/
```

Поиск назад:

```text
?
```

### head

Показывает первые 10 строк:

```bash
head file.txt
```

Показать первые 15 строк:

```bash
head -n 15 file.txt
```

### tail

Показывает последние 10 строк:

```bash
tail file.txt
```

Показать последние 15 строк:

```bash
tail -n 15 file.txt
```

## Создание файлов и каталогов

### touch

Создаёт пустой файл:

```bash
touch file.txt
```

Если файл уже существует, `touch` может обновить его временную метку.

### mkdir

Создаёт каталог:

```bash
mkdir projects
```

### rmdir

Удаляет пустой каталог:

```bash
rmdir projects
```

Если внутри находятся файлы или другие каталоги, команда не сработает.

## Перемещение и удаление

### mv

Используется как для перемещения, так и для переименования. Переименование:

```bash
mv old.txt new.txt
```

Перемещение:

```bash
mv file.txt Documents/
```

### rm

Удаление файла:

```bash
rm file.txt
```

Запрашивать подтверждение:

```bash
rm -i file.txt
```

Принудительное удаление:

```bash
rm -f file.txt
```

Удаление каталога со всем содержимым:

```bash
rm -rf directory
```

`rm -rf` необходимо использовать очень осторожно: команда рекурсивно и без подтверждения удаляет содержимое указанного каталога.

## Ссылки

Linux поддерживает два основных типа ссылок:

```text
Hard Link
Symbolic Link
```

### Жёсткая ссылка

Создаётся:

```bash
ln file1 file2
```

Жёсткая ссылка - ещё одно имя того же файлового объекта. Оба имени указывают на один и тот же `inode`. Посмотреть inode:

```bash
ls -li
```

Если удалить одно имя файла, данные сохранятся, пока существует хотя бы одна жёсткая ссылка на них.

### Символическая ссылка

Создаётся:

```bash
ln -s file1 file2
```

**Symbolic link / symlink** - отдельный объект, который содержит путь к другому файлу или каталогу. Упрощённо она похожа на ярлык:

```text
link -> original_file
```

В отличие от жёсткой ссылки:

- имеет собственный inode.
- может указывать на каталог.
- может указывать на объект в другой файловой системе или на другом диске.
- может указывать даже на несуществующий объект.

Если исходный объект исчезнет, ссылка станет **broken/dangling link**.

## История навигации

Вернуться в предыдущий каталог:

```bash
cd -
```

Также существуют:

```bash
pushd
popd
dirs
```

`pushd` сохраняет посещаемые каталоги в список.

`popd` возвращает к предыдущим каталогам.

`dirs` показывает сохранённый список.

## Стандартные потоки

Каждый процесс по умолчанию имеет три стандартных потока:

| Поток | Название | Номер |
|---|---|---:|
| Стандартный ввод | `stdin` | 0 |
| Стандартный вывод | `stdout` | 1 |
| Ошибки | `stderr` | 2 |

Обычно:

```text
stdin  -> клавиатура
stdout -> терминал
stderr -> терминал
```

## Перенаправление ввода и вывода

### Ввод из файла

```bash
command < input.txt
```

Вместо клавиатуры данные будут получены из файла.

### Вывод в файл

```bash
command > output.txt
```

Результат команды записывается в файл.

### Ошибки в файл

```bash
command 2> errors.txt
```

### Вывод и ошибки в один файл

```bash
command > output.txt 2>&1
```

То есть:

```text
stdout -> output.txt
stderr -> туда же
```

## Каналы - Pipe

Символ:

```text
|
```

Передаёт стандартный вывод одной команды на стандартный ввод другой. Например:

```bash
command1 | command2
```

Можно объединять несколько команд:

```bash
command1 | command2 | command3
```

Такую цепочку называют **pipeline / конвейером**. Идея UNIX/Linux:

```text
несколько небольших программ + pipe = одна сложная операция
```

## Символы подстановки

Shell позволяет выбирать группы файлов по шаблону.

### *

Соответствует любому количеству символов:

```bash
ls *.txt
```

Найдёт все файлы с расширением `.txt`.

### ?

Соответствует одному любому символу:

```bash
ls file?.txt
```

Например:

```text
file1.txt
fileA.txt
```

### [set]

Соответствует одному символу из указанного набора:

```bash
ls file[123].txt
ls file[a-z].txt
```

### [!set]

Соответствует любому символу, кроме указанных:

```bash
ls file[!123].txt
ls file[!a-z].txt
```

## Поиск файлов

### locate

`locate` быстро ищет путь по предварительно созданной базе данных:

```bash
locate filename
```

Преимущество - высокая скорость.

Недостаток - база может быть не полностью актуальной. Обновляется она утилитой:

```bash
updatedb
```

### find

`find` выполняет реальный поиск по файловой системе. Общая структура:

```bash
find <путь> <условия>
```

Поиск по имени:

```bash
find /usr -name gcc
```

Без учёта регистра:

```bash
find /usr -iname gcc
```

Только каталоги:

```bash
find /usr -type d -name gcc
```

Только обычные файлы:

```bash
find /usr -type f -name gcc
```

Основные типы:

```text
f -> обычный файл
d -> каталог
l -> символическая ссылка
```

### Поиск по размеру

Например, файлы больше 10 МБ:

```bash
find / -size +10M
```

Размер можно задавать в:

```text
c -> байты
k -> килобайты
M -> мегабайты
G -> гигабайты
```

### Поиск по времени

Основные параметры:

```text
-atime -> последнее чтение файла
-mtime -> последнее изменение содержимого
-ctime -> изменение метаданных файла
```

Например:

```bash
find / -mtime 3
```

### Выполнение команды над результатами

`find` может запускать команду для найденных файлов с помощью:

```text
-exec
```

Для более безопасного выполнения существует:

```text
-ok
```

`-ok` запрашивает подтверждение перед выполнением действия.

## Управление пакетами

Большая часть программ в Linux устанавливается через **систему управления пакетами**. Менеджеры пакетов:

- устанавливают ПО.
- удаляют его.
- обновляют.
- скачивают пакеты из репозиториев.
- автоматически устанавливают зависимости.

Существует два уровня управления пакетами.

### Низкий уровень

Работает непосредственно с файлами отдельных пакетов:

```text
Debian -> dpkg
Red Hat / SUSE -> rpm
```

### Высокий уровень

Сам скачивает пакеты и работает с зависимостями:

```text
Debian / Ubuntu -> apt / apt-get
Red Hat -> dnf / yum
SUSE -> zypper
```

В обычной работе чаще используется именно высокий уровень.

### Debian / Ubuntu

Установка программы:

```bash
sudo apt install package
```

Поиск:

```bash
apt-cache search package
```

Базовая система пакетов:

```text
dpkg
```

### Red Hat / Fedora

Используется:

```text
dnf
```

Например:

```bash
sudo dnf install package
```

Удаление:

```bash
sudo dnf remove package
```

Обновление:

```bash
sudo dnf update
```

В старых системах часто использовался:

```text
yum
```

### SUSE / openSUSE

Используется:

```text
zypper
```

Он также работает поверх системы пакетов RPM.

## Что важно запомнить

1. Командная строка - один из главных инструментов администрирования Linux.
2. Команда обычно состоит из команды, параметров и аргументов.
3. `sudo` позволяет временно получить административные права.
4. `ssh` используется для удалённого управления Linux-системами.
5. `pwd`, `cd` и `ls` - базовые команды навигации.
6. Абсолютный путь начинается с `/`, относительный - от текущего каталога.
7. `.` означает текущий каталог, `..` - родительский, `~` - домашний.
8. `cat`, `less`, `head` и `tail` используются для просмотра файлов.
9. `touch`, `mkdir`, `mv` и `rm` - основные команды работы с файлами и каталогами.
10. `rm -rf` является потенциально опасной командой.
11. Жёсткая ссылка - дополнительное имя того же inode.
12. Символическая ссылка - отдельная ссылка на путь к объекту.
13. `stdin`, `stdout` и `stderr` имеют номера 0, 1 и 2.
14. `>` перенаправляет вывод, `<` - ввод, `2>` - ошибки.
15. `|` передаёт результат одной команды другой.
16. `*`, `?` и `[]` используются как символы подстановки.
17. `locate` быстро ищет по базе данных, а `find` выполняет реальный поиск.
18. `find` умеет искать по имени, типу, размеру и времени.
19. Для обычной установки программ лучше использовать менеджеры высокого уровня.
20. Ubuntu/Debian используют APT, Fedora/RHEL - `dnf`, openSUSE - `zypper`.
