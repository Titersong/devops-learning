# Работа с текстом

## Введение

В Linux большинство конфигурационных файлов, журналов и результатов выполнения команд представляют собой текстовые данные. Для работы с ними используются утилиты командной строки, которые позволяют:

- просматривать файлы.
- искать определённую информацию.
- фильтровать и изменять текст.
- сортировать и объединять данные.
- автоматизировать повторяющиеся действия.

Особенно полезно объединять несколько команд через `|` (pipe), передавая вывод одной команды на вход другой.

## Просмотр и создание текстовых файлов

## cat

`cat` (concatenate) используется для просмотра и объединения содержимого файлов. Просмотреть файл:

```bash
cat file.txt
```

Объединить два файла:

```bash
cat file1.txt file2.txt > combined.txt
```

Добавить содержимое одного файла в конец другого:

```bash
cat file1.txt >> file2.txt
```

Создать файл вручную:

```bash
cat > file.txt
```

Ввести текст, затем нажать `Ctrl+D` для завершения ввода.

## tac

`tac` показывает строки файла в обратном порядке:

```bash
tac file.txt
```

Последняя строка будет выведена первой.

## echo

`echo` выводит текст или значения переменных.

```bash
echo "Hello Linux"
```

Записать текст в файл:

```bash
echo "Hello" > file.txt
```

Добавить строку:

```bash
echo "World" >> file.txt
```

Вывести переменную:

```bash
echo $HOME
```

Важно различать:

```text
>  -> перезаписать содержимое файла
>> -> добавить данные в конец
```

## Работа с большими файлами

## less

`less` позволяет просматривать большие текстовые файлы без необходимости загружать их целиком в редактор.

```bash
less file.txt
```

Особенно удобен для журналов и больших конфигурационных файлов. Основные клавиши:

```text
Space -> следующая страница
b     -> предыдущая страница
/text -> поиск текста
q     -> выход
```

## head и tail

`head` показывает первые 10 строк файла:

```bash
head file.txt
```

Первые 5 строк:

```bash
head -n 5 file.txt
```

`tail` показывает последние 10 строк:

```bash
tail file.txt
```

Последние 15 строк:

```bash
tail -n 15 file.txt
```

## tail -f

Используется для отслеживания новых строк файла в реальном времени:

```bash
tail -f application.log
```

Особенно полезно при наблюдении за логами работающих программ. Остановить просмотр:

```text
Ctrl + C
```

## Работа со сжатыми файлами

Для файлов `.gz` существуют специальные команды, позволяющие работать с ними без предварительной ручной распаковки.

```text
zcat  -> показать содержимое
zless -> постраничный просмотр
zgrep -> поиск текста
zdiff -> сравнение файлов
```

Примеры:

```bash
zless archive.log.gz
```

```bash
zgrep "error" archive.log.gz
```

Для других форматов существуют аналогичные утилиты, например `bzcat` и `xzcat`.

## Поиск текста и регулярные выражения

## Регулярные выражения (Regex)

**Регулярные выражения** - специальные шаблоны для поиска и обработки текста. Используются в:

- `grep`.
- `sed`.
- `awk`.
- текстовых редакторах.
- языках программирования.

Основные символы:

| Символ | Значение |
|---|---|
| `.` | любой один символ |
| `^` | начало строки |
| `$` | конец строки |
| `*` | повторение предыдущего элемента 0 или более раз |
| `a\|b` | a или b (в расширенных regex) |

Примеры:

```text
^Error  -> строки, начинающиеся с Error
end$    -> строки, заканчивающиеся на end
a.*     -> a и любые следующие символы
```

Важно: регулярные выражения отличаются от символов подстановки Shell (`*.txt`, `file?.txt`).

## grep

`grep` - одна из самых полезных команд для поиска текста в файлах. Она выводит строки, соответствующие заданному шаблону. Основной синтаксис:

```bash
grep "pattern" file.txt
```

Например:

```bash
grep "error" application.log
```

Покажет строки, содержащие `error`.

## Основные параметры grep

```text
-i -> игнорировать регистр
-v -> вывести строки без совпадения
-n -> показать номера строк
-C -> показать контекст вокруг совпадения
```

Примеры:

Поиск без учёта регистра:

```bash
grep -i "error" application.log
```

Показать строки, НЕ содержащие `error`:

```bash
grep -v "error" application.log
```

Показать три строки до и после совпадения:

```bash
grep -C 3 "error" application.log
```

## grep с регулярными выражениями

Найти строки, содержащие цифры:

```bash
grep '[0-9]' file.txt
```

Найти строки, начинающиеся с `Error`:

```bash
grep '^Error' file.txt
```

Найти строки, содержащие `error` или `warning`:

```bash
grep -E 'error|warning' file.txt
```

`-E` включает расширенные регулярные выражения.

## sed

**sed (Stream Editor)** - инструмент для автоматического редактирования и преобразования текстовых потоков. Чаще всего применяется для:

- замены текста.
- обработки строк.
- преобразования содержимого файлов.

## Замена текста

Общий синтаксис:

```bash
sed 's/old/new/' file.txt
```

Заменяет первое совпадение в каждой строке. Заменить все совпадения:

```bash
sed 's/old/new/g' file.txt
```

Здесь:

```text
s -> substitute (замена)
g -> global (все совпадения в строке)
```

Например:

```bash
echo "I hate Linux" | sed 's/hate/love/'
```

Результат:

```text
I love Linux
```

## Замена в определённых строках

```bash
sed '1,3s/old/new/g' file.txt
```

Заменяет совпадения только в строках 1–3.

## Изменение исходного файла

По умолчанию `sed` выводит результат, не изменяя исходный файл. Для непосредственного изменения используется:

```bash
sed -i 's/old/new/g' file.txt
```

**Важно:** `-i` изменяет исходный файл. Перед использованием лучше сделать резервную копию или сначала проверить результат без `-i`. Можно записать результат в отдельный файл:

```bash
sed 's/old/new/g' file1.txt > file2.txt
```

## awk

**awk** - инструмент и интерпретируемый язык для извлечения, фильтрации и обработки структурированных текстовых данных. Он особенно удобен при работе с текстом, разделённым на столбцы. Основные понятия:

```text
Record -> запись (обычно строка)
Field  -> поле (обычно столбец)
```

## Основной синтаксис

```bash
awk '{ print $1 }' file.txt
```

Вывести первый столбец файла. В awk используются:

```text
$0 -> вся строка
$1 -> первое поле
$2 -> второе поле
$3 -> третье поле
```

Например:

```bash
awk '{ print $1, $3 }' file.txt
```

Выведет первый и третий столбцы.

## Разделители

Параметр `-F` позволяет выбрать разделитель полей. Например, `/etc/passwd` использует двоеточие `:`.

```bash
awk -F: '{ print $1 }' /etc/passwd
```

Выведет имена пользователей.

```bash
awk -F: '{ print $1, $7 }' /etc/passwd
```

Выведет имена пользователей и указанные для них оболочки.

## Разница между sed и awk

```text
sed -> преобразование и замена текста
awk -> извлечение и обработка полей, структурированных данных
```

## Сортировка и объединение данных

## sort

`sort` сортирует строки текстового файла.

```bash
sort file.txt
```

В обратном порядке:

```bash
sort -r file.txt
```

По третьему полю:

```bash
sort -k 3 file.txt
```

Вывести только уникальные строки:

```bash
sort -u file.txt
```

## uniq

`uniq` удаляет последовательные повторяющиеся строки.

```bash
uniq file.txt
```

Важно: `uniq` обрабатывает только повторы, расположенные рядом. Поэтому обычно используют:

```bash
sort file.txt | uniq
```

Подсчитать количество повторений:

```bash
sort file.txt | uniq -c
```

## paste

`paste` объединяет строки нескольких файлов по их положению.

```bash
paste file1.txt file2.txt
```

Например:

```text
file1       file2

Alice       100
Bob         200
```

Результат:

```text
Alice  100
Bob    200
```

Изменить разделитель:

```bash
paste -d, file1.txt file2.txt
```

## join

`join` объединяет строки двух файлов по общему полю. В отличие от `paste`, который просто соединяет строки по порядку, `join` сопоставляет значения общего поля.

```bash
join file1.txt file2.txt
```

Это похоже на объединение таблиц по общему ключу.

## split

`split` разделяет большой файл на несколько частей.

```bash
split bigfile.txt
```

По умолчанию создаёт части по 1000 строк. Указать собственный префикс:

```bash
split bigfile.txt part_
```

Получатся файлы вроде:

```text
part_aa
part_ab
part_ac
```

Исходный файл остаётся без изменений.

## Дополнительные инструменты обработки текста

## strings

`strings` извлекает читаемые текстовые строки из файлов, включая бинарные.

```bash
strings program.bin
```

Можно объединять с `grep`:

```bash
strings program.bin | grep "version"
```

## tr

`tr` используется для замены, удаления или преобразования символов в текстовом потоке. Превратить строчные буквы в заглавные:

```bash
echo "hello" | tr 'a-z' 'A-Z'
```

Результат:

```text
HELLO
```

Удалить определённый символ:

```bash
echo "test" | tr -d 't'
```

Результат:

```text
es
```

Удалить повторяющиеся пробельные символы:

```bash
echo "Hello    Linux" | tr -s ' '
```

## tee

`tee` позволяет одновременно:

- показывать вывод команды в терминале.
- записывать его в файл.

Например:

```bash
ls -l | tee output.txt
```

Результат будет показан на экране и сохранён в `output.txt`.

## wc

`wc` (Word Count) используется для подсчёта строк, слов и байтов.

```text
-l -> строки
-w -> слова
-c -> байты
```

Пример:

```bash
wc -l file.txt
```

Покажет количество строк.

```bash
wc -w file.txt
```

Покажет количество слов.

## cut

`cut` извлекает определённые поля из текста. Основные параметры:

```text
-d -> разделитель
-f -> номер поля
```

Например:

```bash
cut -d: -f1 /etc/passwd
```

Выведет первый столбец, используя `:` как разделитель.

## Практические примеры

### Найти ошибки в логах

```bash
grep -i "error" application.log
```

### Подсчитать количество строк с ошибками

```bash
grep -i "error" application.log | wc -l
```

### Найти самые часто повторяющиеся строки

```bash
sort application.log | uniq -c
```

### Посмотреть новые записи в логах

```bash
tail -f application.log
```

### Вывести пользователей системы

```bash
awk -F: '{ print $1 }' /etc/passwd
```

### Сохранить вывод команды и одновременно показать его

```bash
ls -l | tee result.txt
```
