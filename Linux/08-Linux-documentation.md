# Поиск документации Linux

## Основные источники документации

В Linux не нужно помнить все команды и их параметры наизусть. Для этого существуют встроенные справочные системы. Основные источники:

- `man`.
- `info`.
- `--help` и `-h`.
- команда `help`.
- пакетная документация.
- документация дистрибутива и интернет-ресурсы.

## man

`man` - основной способ просмотра подробной документации по командам и системным компонентам. Пример:

```bash
man ls
```

Также можно искать связанные страницы:

```bash
man -f command
```

Эквивалент:

```bash
whatis command
```

Поиск страниц, связанных с определённой темой:

```bash
man -k keyword
```

Эквивалент:

```bash
apropos keyword
```

Если у темы существует несколько man-страниц:

```bash
man -a command
```

## info

`info` - справочная система проекта GNU. Открыть список доступной документации:

```bash
info
```

Открыть документацию по конкретной теме:

```bash
info command
```

Основные клавиши:

```text
q -> выйти
h -> помощь
Enter -> открыть пункт
n -> следующий раздел
p -> предыдущий раздел
u -> уровень выше
```

## --help

Для быстрой справки большинство команд поддерживают:

```bash
command --help
```

или:

```bash
command -h
```

Например:

```bash
man --help
```

`--help` обычно удобнее, когда нужно быстро вспомнить синтаксис или параметры команды.

## Команда help

Некоторые команды, например `cd` и `echo`, встроены непосредственно в Bash. Для получения справки по таким командам используется:

```bash
help
```

или:

```bash
help cd
```

## Другие источники документации

### Пакетная документация

Документация установленных программ часто находится в:

```text
/usr/share/doc
```

### Документация дистрибутива

Полезную информацию также можно найти в официальной документации:

- Ubuntu.
- Fedora.
- openSUSE.
- Gentoo.
- других дистрибутивов.

Также можно использовать форумы, Wiki и другие интернет-ресурсы.

## Что важно запомнить

1. Не нужно запоминать все параметры Linux-команд.
2. `man` - основной источник подробной документации.
3. `--help` / `-h` - быстрая справка.
4. `info` используется для документации GNU.
5. `help` показывает справку по встроенным командам Bash.
6. `whatis` или `man -f` показывает краткое описание команды.
7. `apropos` или `man -k` помогает найти команды по теме.
8. Документация пакетов обычно находится в `/usr/share/doc`.
