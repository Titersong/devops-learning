# Установка Git

Обычно Git устанавливают с помощью готового бинарного пакета через менеджер пакетов операционной системы. Это проще, чем собирать программу из исходного кода, поскольку необходимые зависимости устанавливаются автоматически. Проверить наличие и версию Git можно командами:

```bash
$ which git
$ git --version
```

Команда `which git` показывает путь к исполняемому файлу Git в Linux.

## Linux

Команда установки зависит от дистрибутива.

### Debian и Ubuntu

```bash
sudo apt-get install git
```

### Fedora, RHEL и CentOS

```bash
sudo dnf install git
```

### SUSE

```bash
sudo zypper install git git-core
```

Точные названия пакетов могут отличаться в зависимости от дистрибутива и его версии.

## Windows

В Windows можно установить отдельный пакет Git for Windows. После установки Git будет доступен через Git Bash, PowerShell или терминал.

Проверить установку:

```powershell
git --version
```

Также Git можно установить через среду Cygwin.

## Установка из исходного кода

Сборка из исходного кода может понадобиться, если нужна более новая версия Git, которой ещё нет в репозиториях операционной системы. Исходный код можно клонировать из официального репозитория:

```bash
git clone -v https://github.com/git/git.git
cd git
make
sudo make install
```

Во время компиляции могут понадобиться дополнительные библиотеки и пакеты разработки.

## Что важно запомнить

1. Проще всего устанавливать Git через менеджер пакетов своей операционной системы.
2. Команда `git --version` показывает установленную версию Git.
3. Команда `which git` показывает расположение Git в Linux.
4. Команды установки отличаются между дистрибутивами Linux.
5. Сборка из исходного кода нужна в основном для получения самой новой версии Git.
