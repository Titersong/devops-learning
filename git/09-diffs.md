# Получение различий (diff)

## Обычная команда diff

Команда `diff` сравнивает два файла и показывает различия между ними:

```bash
diff file1 file2
```

Более удобный унифицированный формат выводится с параметром `-u`:

```bash
diff -u file1 file2
```

В таком выводе:

- `---` обозначает первый файл.
- `+++` обозначает второй файл.
- `-` показывает удалённые строки.
- `+` показывает добавленные строки.
- `@@` указывает номера строк, к которым относятся изменения.

Сравнить два каталога рекурсивно можно командой:

```bash
diff -Nur directory1 directory2
```

Где:

- `-r` рекурсивно сравнивает подкаталоги.
- `-N` учитывает файлы, существующие только в одном из каталогов.
- `-u` использует унифицированный формат.

## Получение различий в Git

Чтобы показать изменения в рабочем каталоге, которые ещё не были добавлены в индекс используется команда:

```bash
git diff
```

Чтобы сравнить рабочие файлы с определённым коммитом:

```bash
git diff <commit>
```

Например:

```bash
git diff HEAD~2
```

## Изменения в индексе

Посмотреть изменения, подготовленные для следующего коммита:

```bash
git diff --cached
```

Также можно использовать более понятное название:

```bash
git diff --staged
```

Обе команды показывают различия между индексом и последним коммитом `HEAD`. Можно сравнить индекс с другим коммитом:

```bash
git diff --staged <commit>
```

## Сравнение коммитов и веток

Сравнить два коммита:

```bash
git diff <commit1> <commit2>
```

Названия веток также можно использовать как ссылки на их последние коммиты:

```bash
git diff branch1 branch2
```

Таким образом можно посмотреть различия между двумя ветками.

## Форматы вывода

Показать краткую статистику изменений:

```bash
git diff --stat branch1 branch2
```

Она показывает названия изменённых файлов и приблизительное количество добавленных и удалённых строк. Показать числовую статистику:

```bash
git diff --numstat branch1 branch2
```

Она выводит для каждого файла добавленные строки, удалённые строки и имя файла. Игнорировать различия в пробелах:

```bash
git diff --ignore-all-space
```

## Ограничение области сравнения

Можно сравнивать изменения только в определённом файле или каталоге:

```bash
git diff <commit1> <commit2> <path>
```

Например:

```bash
git diff v4.2.1 v4.2.2 Documentation/vm
```

Показать только статистику для определённого каталога:

```bash
git diff --stat v4.2.1 v4.2.2 arch/x86_64
```

## Основные варианты git diff

```text
git diff
Рабочий каталог -> индекс

git diff --staged
Индекс -> последний коммит

git diff <commit>
Рабочий каталог -> указанный коммит

git diff <commit1> <commit2>
Первый коммит -> второй коммит
```

## Что важно запомнить

1. `diff -u` показывает различия между обычными файлами в унифицированном формате.
2. `git diff` показывает изменения, ещё не добавленные в индекс.
3. `git diff --staged` показывает изменения, подготовленные для следующего коммита.
4. `git diff <commit1> <commit2>` сравнивает два коммита или две ветки.
5. `--stat` выводит краткую статистику изменений.
6. `--numstat` выводит количество добавленных и удалённых строк для каждого файла.
7. Сравнение можно ограничить определённым файлом или каталогом.
