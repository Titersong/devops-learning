# Вступ до Git

## Git
Git - это система контроля версий. Она позволяет узнать, кто и когда внёс изменение, сравнивать разные состояния проекта, возвращаться к предыдущим версиям и объединять работу нескольких разработчиков. Git является распределённой системой контроля версий. После клонирования репозитория разработчик получает не только текущие файлы, но и локальную копию истории проекта. Поэтому многие операции, например просмотр истории, создание коммитов и веток, можно выполнять без подключения к интернету.

## Подтверждение происхождения изменений: CLA и DCO

В open-source проектах для подтверждения права на внесённый код могут использоваться CLA и DCO. CLA - отдельное соглашение между разработчиком и проектом. DCO - подтверждение того, что разработчик имеет право отправить этот код. Если проект использует DCO, к коммиту добавляют параметр `-s`:
`$ git commit -s`
Он добавляет строку:
`Signed-off-by: Some Developer <some-developer@example.com>`

## Доступные системы управления версиями

Систем управления версия в мире очень много, и существуют они примерно с 1970-х годов. Первой из них была Система управления исходным кодом (Source Code Control System, SCCS). Но в наше время их стало намного больше, и Git занимает там лидирующую позицию. Список известных систем контроля версиями:
- Система управления версиями RCS
- Система управления версиями CVS
- Subversion
- Git
- Bazaar
- Monotone
- Mercurial
- Project Revision Control System (PRCS)

## Графические интерфейсы

Существует несколько графических интерфейсов, которые можно использовать для просмотра или управления Git-репозиториями:
1. git-gui - Для использования достаточно запустить программу из главного каталога репозитория, введя git gui или git-gui.
2. gitk - Этот браузер репозитория можно запустить из git-gui; он представляет собой несколько устаревший интерфейс, в большей степени предназначенный для просмотра истории проекта.
3. cgit - Может быть установлен вместе с веб-сервером для обеспечения очень эффективного просмотра репозитория. Пример: https://www.kernel.org.
4. gitweb - Интерфейс более устаревший, чем у cgit, но работает по схожему принципу.

## Документация

Для просмотра документации и списка доступных команд Git, достаточно воспользоваться данными командами:
- `$ git help`
- `$ git help <command>`           (пример git help branch)
- `$ git <command> --help`         (пример git branch --help)
- `$ git <command> -h`             (пример git branch -h)

## Что важно запомнить

1. Git - распределённая система контроля версий.
2. Репозиторий содержит проект и историю его изменений.
3. Большинство операций Git выполняется локально.
4. DCO и CLA - разные способы подтверждения прав на вклад.
5. `git commit -s` добавляет строку `Signed-off-by`.
6. Для Git существуют графические интерфейсы.
7. `git help <command>`
